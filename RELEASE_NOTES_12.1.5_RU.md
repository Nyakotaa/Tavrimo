# Tavrimo 12.1.5 — импорт ICS и исправление определения группы

## Исправления

- В настройках → «Импортировать» теперь можно выбирать и резервные копии `.json`, и календари `.ics`. Формат определяется по расширению и MIME-типу.
- `.ics` направляется в импорт расписания, `.json` — в прежний импорт резервной копии.
- Добавлена нормализация латинских букв, часто вводимых вместо кириллических при наборе номера группы на английской раскладке. Это помогает находить встроенное расписание `15.14Д-ГГ04/266`.
- Ручной импорт ICS теперь считается локальным источником: фоновая синхронизация не пытается повторно обращаться к порталу РЭУ и не показывает 403 для уже импортированного расписания.
- Импорт проверяет соответствие названия календаря выбранной группе, читает UTF-8 и показывает конкретную причину ошибки.
- Service Worker и URL ресурсов переведены на версию 12.1.5 для сброса старого кэша 12.1.4.

## Сохранность данных

- JSON-импорт резервной копии остался отдельным и сохраняет прежнее подтверждение перед заменой данных.
- Импорт ICS не заменяет задачи, настройки и статистику; обновляется только расписание выбранной группы.
- При ошибке чтения старое расписание остаётся без изменений.

## Проверка

- Проверяется импорт ICS из обоих элементов выбора файла.
- Проверяется встроенное расписание при HTTP 403/503 и на английской раскладке.
- Регрессионный набор запускается через `node tools/run_regression.mjs`.
