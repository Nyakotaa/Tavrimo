FLOWDAY OFFLINE — КАК ПОЛЬЗОВАТЬСЯ БЕЗ ИНТЕРНЕТА

1. Размести папку сайта на HTTPS-хостинге.
2. Один раз открой сайт в Safari на iPhone при включённом интернете.
3. Нажми «Поделиться» → «На экран “Домой”».
4. Запусти Flowday с иконки на домашнем экране.
5. После того как приложение хотя бы один раз полностью открылось, можно включить авиарежим — Flowday продолжит работать.

Важно: просто переслать index.html в Telegram и открыть его как файл недостаточно — iOS не сможет установить Service Worker для file://.

Все задачи и настройки остаются локально на устройстве. Синхронизации между телефонами в этой версии нет.
