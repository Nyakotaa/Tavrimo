# Tavrimo 12.1.6 — дополнительные расписания групп

## Что изменилось

- Добавлен второй проверенный календарный снимок Vuzio для группы `15.14Д-ММ05/26б`.
- Снимок содержит 48 занятий за 16–30 ноября 2026 года.
- Календарь проверяется текущим ICS-парсером: распознаны все 48 событий, неизвестных часовых поясов и неподдерживаемых повторений нет.
- В поле выбора группы появились подсказки с доступными локальными календарями. Свободный ввод группы сохранён.
- Service Worker предварительно кэширует новый ICS, чтобы выбранный календарь был доступен офлайн после установки/обновления приложения и первичной загрузки оболочки.
- Существующая группа `15.14Д-ГГ04/266`, ручной импорт ICS, задачи, локальное хранение и прежний Sync Gateway не заменялись.

## Ограничения

Каталог содержит две подтверждённые группы: `15.14Д-ГГ04/266` и `15.14Д-ММ05/26б`. Повторяющиеся ссылки на один и тот же Vuzio feed не дают календарей остальных групп. Для расширения каталога нужны отдельные уникальные ICS-файлы или проверка live Sync Gateway для каждой группы. Снимки статические и не получают изменения Vuzio автоматически.

## Проверка

- ICS `15.14Д-ММ05/26б`: 48 из 48 событий распознаны.
- Даты покрытия: 2026-11-16 — 2026-11-30.
- Совместимость: проверена текущим парсером.
- Полный регрессионный набор: результаты перечислены в `QA_12.1.6_RU.md`.
