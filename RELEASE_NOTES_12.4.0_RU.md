# Tavrimo 12.4.0 — единый календарь и профиль

## Что изменилось

- Все календарные события отображаются вместе на экранах «Сегодня» и «Неделя».
- Импорт календарей выполняется вручную из файлов `.ics` прямо на экране «Сегодня».
- Поддержка повторений, часовых поясов, событий на весь день и многодневных событий сохранена.
- Ранее сохранённые пары РЭУ переносятся в локальный календарь с сохранением исходных ID и ссылок задач `linkedUniversityEventId`.
- Уже загруженные события внешних feed-календарей сохраняются локально; секретные URL очищаются.
- Автоматические обращения к расписанию РЭУ и calendar feeds отключены.
- В «Ещё» остались три пункта: Профиль, Фокус, Настройки.
- В профиле можно задать имя и локальное фото; статистика и состояние плана доступны там же.
- Настройки планирования, экспорт/импорт JSON, подтверждение сброса и офлайн-хранение сохранены.

## Совместимость

- `SCHEMA_VERSION = 17`.
- `STORAGE_KEY = 'tavrimo-planner-v17'`.
- Старые JSON-резервные копии продолжают импортироваться.
- Фото профиля сжимается до квадратного JPEG 320×320 и хранится локально в JSON-данных.
- Пары РЭУ и ссылки задач на них не получают новые ID.

## Ограничения

В 12.4.0 нет автоматического обновления расписания и нет подписок по URL. Для получения новых событий из календаря экспортируй актуальный `.ics` и импортируй его снова.


## Hotfix: navigation restored

The navigation crash was caused by treating the result of `querySelector()` as a collection. The tab list now uses `querySelectorAll()`. A new navigation smoke test verifies all five screens and the active topbar/nav state.

CI on hotfix commit `1dbee0d`: **11/11 regression tests passed**.


## Фирменная заставка запуска

При открытии PWA показывается оригинальный знак Tavrimo, надпись TAVRIMO и анимированная полоса загрузки. Заставка закрывается после отрисовки Today. При повторных запусках Service Worker сначала отдаёт сохранённую HTML/CSS/JS-оболочку, поэтому установленное приложение не ждёт пробуждения Render, чтобы показать интерфейс.
