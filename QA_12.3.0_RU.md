# Tavrimo 12.3.0 — отчёт проверки

## Объём обновления

- Несколько внешних календарей отдельно от календаря РЭУ.
- Импорт одного или нескольких `.ics`-файлов.
- Read-only iCalendar URL для Google Calendar, Outlook и iCloud через новый endpoint Sync Gateway.
- Включение, отключение, ручное обновление и удаление каждого внешнего календаря.
- Внешние события появляются на экране «Сегодня» и в «Мой план», учитываются в занятости и конфликт-проверке ручного планирования.
- Последний успешный снимок остаётся локально доступным офлайн.
- Имя для приветствия задаётся в профиле, приветствие строится по локальному времени устройства.
- Схема данных остаётся v17; старые задачи, календарь РЭУ и резервные копии обратно совместимы.

## Выполненные проверки

Среда: Node.js, локальная файловая копия релиза 12.3.0.

Команды:

```bash
node --check app.js
node --check sync-service/server.mjs
node --check sync-service/calendar-feed.mjs
node tools/run_regression.mjs
```

## Что не проверено в этой среде

- Нет реального браузерного end-to-end прогона на опубликованном GitHub Pages.
- Не выполнялся live import секретных ссылок из настоящих Google/Outlook/iCloud аккаунтов.
- Не запускался обновлённый Express/Playwright Gateway на Render; локальные `sync-service` зависимости в среде не установлены.
- Не подтверждён новый endpoint `POST /api/calendar/feed` на production до деплоя обновлённого backend.

Поэтому до обновления Render работают локальный импорт `.ics` и персональное приветствие; URL-подписки требуют backend deploy.

## Ограничения функциональности

- Подключение Google/Outlook/iCloud — read-only iCalendar, не OAuth-вход и не двустороннее редактирование.
- Секретные feed URL хранятся локально и экспортируются в JSON backup. Резервные копии с такими ссылками нужно считать конфиденциальными.
- Поддерживаются распространённые DAILY/WEEKLY/MONTHLY/YEARLY RRULE; редкие сложные правила повторения, отдельные overrides и нестандартные VTIMEZONE могут отображаться не полностью.
- Обновление внешних URL-календарей выполняется при запуске/возврате в PWA и примерно каждые 30 минут, пока PWA открыта и есть интернет. Реальная свежесть зависит от провайдера.
