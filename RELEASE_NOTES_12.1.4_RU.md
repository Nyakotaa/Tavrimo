# Tavrimo 12.1.4 — исправление загрузки демонстрационного расписания

## Исправление

- Демонстрационный ICS для `15.14Д-ГГ04/266` встроен непосредственно в `app.js`.
- Известная группа теперь разрешается до любого сетевого запроса: Sync Gateway не вызывается для неё, поэтому его HTTP 503/режим сна Render не блокирует показ занятий.
- Добавлен явный алиас `15.14Д-ГГ04/26б` для варианта написания, который присутствует в `X-WR-CALNAME` календаря Vuzio.
- Проверка локального снимка выполняется раньше cooldown предыдущей live-синхронизации.
- Для других групп сохранён прежний fallback к Sync Gateway.
- Внешние `manifest.json` и `.ics` оставлены для дальнейшего расширения каталога, но демонстрационная группа больше от них не зависит.

## Данные

- 46 реальных событий из пользовательской календарной ленты Vuzio.
- Период: 9–23 ноября 2026 года.
- Часовой пояс: `Europe/Moscow`; исходные события UTC преобразуются существующим ICS-парсером.
- Секретный URL подписки в сборку не включён.
