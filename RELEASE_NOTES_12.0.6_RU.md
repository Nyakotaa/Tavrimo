# Tavrimo 12.0.7 — REA Sync Refresh Fix

## Что исправлено

- Кнопки «Обновить» напрямую привязаны к обработчику и всегда отправляют `force=1`; серверный TTL-кэш обходится при ручном обновлении.
- При активной синхронизации повторное нажатие отменяет текущий запрос и запускает новый.
- После ошибки кнопка становится «Повторить», а состояние синхронизации остаётся видимым.
- Поиск РЭУ теперь явно выбирает вкладку «Группы».
- Поддерживается icon-only search (`search`), `<select>` с вариантами групп и кликабельные listbox/result nodes.
- Сопоставление группы нормализует регистр, `ё/е`, пробелы и типографские дефисы.
- Обновление самого портала выполняется только после выбора группы, чтобы не сбрасывать поиск.
- Service Worker официального портала не блокируется.
- Исправлен cache-busting и домашняя iOS-иконка `apple-touch-icon-v16.png`.

## Что проверить после деплоя

1. Render должен стать `Live`.
2. `/api/rea/health` должен вернуть `ok: true` и `executableExists: true`.
3. В Tavrimo выбрать группу и нажать «Обновить».
4. В логах Render при принудительном обновлении должен быть запрос с `force=1`; после выбора группы — `[REA_SEARCH_OK]`.
