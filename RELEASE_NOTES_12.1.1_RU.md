# Tavrimo 12.1.1 — Reliability Hardening

## Исправления и улучшения надёжности

- Перед импортом резервной копии показывается предупреждение: импорт заменяет текущие задачи, настройки, статистику и локальное расписание.
- При отказе LocalStorage сохранить импортированные данные прежнее состояние приложения восстанавливается в памяти.
- Ограничен размер кэша расписаний (200 записей); устаревшие записи удаляются.
- Лимитер использует IP-адрес, рассчитанный Express с учётом настроенной доверенной прокси-цепочки, а не исходное значение `X-Forwarded-For`, которое клиент может подделать.
- Ограничен размер таблицы лимитера и очищаются устаревшие IP-записи.
- При следующем запросе Gateway обнаруживает отключённый Chromium и пытается создать новое подключение.
- Если портал не отдаёт экспорт «За всё время», сервер не принимает видимую неделю за полный календарь: запрос завершается понятной ошибкой, а ранее сохранённое расписание остаётся нетронутым.
- Проверка `/api/rea/health` теперь означает, что процесс сервера жив. Отдельный `/api/rea/ready` активно запускает Chromium и проверяет создание контекста браузера. Render продолжает использовать liveness endpoint, чтобы не перезапускать сервер только потому, что браузер ещё не запускался.
- Обновлены cache-busting версии PWA и Service Worker.

## Что ещё не подтверждено

Живая синхронизация с `rasp.rea.ru` и развёрнутым Render Gateway не проверена этим локальным релизом. Для подтверждения требуется проверить `/api/rea/ready`, поиск конкретной группы и получение календаря за несколько недель на опубликованном сервере.

## Проверки

Актуальные регрессионные тесты и синтаксические проверки должны пройти локально и в GitHub Actions. Исторические тесты 12.0.x не являются тестами текущего релиза.
