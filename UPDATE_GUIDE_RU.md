# Обновление Tavrimo — быстрый гайд

1. Распакуй новую версию.
2. Открой свой репозиторий GitHub.
3. Нажми `Add file → Upload files`.
4. Перетащи новые файлы поверх старых.
5. Нажми `Commit changes`.
6. Подожди обновления GitHub Pages.
7. Открой Tavrimo на iPhone с интернетом.
8. Нажми `Обновить`, если появится такой баннер.

Не создавай вторую папку `personal-planner` внутри репозитория. Файл `index.html` должен лежать в корне публикации.

Перед крупным обновлением рекомендуется сделать `Настройки → Экспортировать`.
