# Обновление Tavrimo 12.0.0

## Если PWA + Gateway размещены на одном сервере
1. Замените файлы проекта новыми.
2. Перезапустите контейнер/Node-процесс.
3. Откройте Tavrimo на iPhone с интернетом.
4. Нажмите «Обновить», если приложение покажет баннер новой версии.

## Если PWA на GitHub Pages
1. Замените файлы `personal-planner` в репозитории.
2. Убедитесь, что `config.js` содержит URL Sync Gateway.
3. Дождитесь публикации GitHub Pages.
4. Откройте Tavrimo на iPhone с интернетом, чтобы Service Worker получил новую версию.

Локальные задачи и сохранённое расписание хранятся в браузере пользователя и не должны удаляться только из-за обновления файлов приложения.
