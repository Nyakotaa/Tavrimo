# Flowday

**Flowday** — персональный планировщик задач для iPhone в формате offline-first PWA. Он превращает список дел в реальное расписание: учитывает дедлайн (в том числе время), приоритет, длительность, рабочие часы, перерыв, буфер и вручную закреплённые блоки.

## Что умеет
- автоматическое планирование по свободным окнам до дедлайна;
- дедлайн с датой и необязательным точным временем;
- длительность реально определяет размер слота и нагрузку дня;
- приоритет влияет на порядок задач внутри близких сроков;
- ручное назначение даты и времени с проверкой рабочего дня, дедлайна и конфликтов;
- редактирование задачи с автоматическим перепланированием, если изменились срок, приоритет или длительность;
- недельный обзор и процент занятости рабочего времени;
- библиотека задач с поиском и фильтрами;
- режим фокуса и статистика;
- светлая, тёмная и системная тема;
- локальное хранение без аккаунта и сервера;
- экспорт и импорт резервной копии;
- работа офлайн после первого открытия;
- уведомление о доступной новой версии через Service Worker.

## Быстрый запуск через GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. В `Settings → Pages` выберите `Deploy from a branch → main → /(root)`.
4. Откройте опубликованный HTTPS-адрес через Safari на iPhone.
5. Выберите `Поделиться → На экран «Домой»`.

## Обновление
Замените файлы в репозитории файлами новой версии и сделайте commit. Flowday использует версионированный Service Worker: при обнаружении новой версии появится кнопка **«Обновить»**.

## Логика планирования
- **Дедлайн** — жёсткий верхний предел: Flowday не ставит задачу после выбранной даты и времени. Если точное время не задано, крайним моментом считается конец дня.
- **Приоритет** — определяет порядок задач с близкими дедлайнами: высокий ставится раньше среднего, средний раньше низкого.
- **Длительность** — реальный размер блока: двухчасовая задача не может занять 60 минут и не помещается в окно короче двух часов.
- **Ручное размещение** — фиксирует слот и исключает задачу из автоперестроения. Перед сохранением проверяются рабочие часы, перерыв, дедлайн и конфликты с другими задачами.
- **Буфер** — резервирует дополнительное время между задачами при автопланировании и ручной проверке конфликтов.
- **Выходные** — разрешают планировщику использовать субботу и воскресенье.

## Данные
Задачи и настройки хранятся локально на устройстве. GitHub Pages не получает содержимое ваших задач. Резервную копию можно экспортировать из `Ещё → Настройки`.

## Иконка
Используйте исходник PNG **1024×1024** и положите его в `assets/icons/source-icon-1024.png`. Скрипт `tools/build_icons.py` создаёт нужные размеры. Для iPhone Web App используется `apple-touch-icon` 180×180.

## Структура
- `index.html` — интерфейс;
- `app.js` — логика и планировщик;
- `style.css` — оформление;
- `manifest.webmanifest` — PWA manifest;
- `sw.js` — offline cache и обновления;
- `assets/icons/` — иконки;
- `docs/` — инструкции;
- `tools/` — утилиты и проверки.
