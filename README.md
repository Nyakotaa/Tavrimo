# Flowday — обновлённый offline-first PWA

Версия 3 — iOS-first интерфейс без перегруза главного экрана.

## Что нового
- Новый спокойный главный экран с одной сводкой дня и компактным маршрутом.
- Отдельные экраны: Сегодня, Неделя, Задачи, Ещё.
- Режим фокуса с настраиваемой длительностью.
- Статистика недели с графиком.
- Отдельное окно «Как Flowday планирует».
- Расширенные настройки: рабочее время, обед, буфер, фокус и тема (системная/светлая/тёмная).
- Более плавные переходы, stagger-анимации карточек, sheet-анимации и поддержка prefers-reduced-motion.
- Сохранена логика автопланирования, ручные слоты, импорт/экспорт и локальное хранение.
- Offline-first Service Worker, cache-first для приложения.

## Установка на iPhone
1. Разместите папку с `index.html` на HTTPS-хостинге.
2. Откройте ссылку в Safari.
3. Нажмите «Поделиться» → «На экран “Домой”».
4. Первый запуск должен быть с интернетом, чтобы Service Worker закэшировал приложение.
5. После этого Flowday можно использовать без интернета.

## Важно
Данные задач и настроек хранятся локально на каждом устройстве. Серверная синхронизация не используется.

## Иконка
Для своей иконки приложения используйте PNG 1024×1024 px и замените `icon-180.png`.
