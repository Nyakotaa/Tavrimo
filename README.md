# Flowday — iOS-ориентированный персональный планировщик

Это мобильный PWA-порт Flowday: приложение выглядит и работает как iPhone-приложение, устанавливается на домашний экран и умеет работать офлайн после первого открытия.

## Что работает

- Автоматическое планирование задач по свободным окнам до дедлайнов.
- Приоритет, дедлайн, длительность и рабочие часы участвуют в расчёте порядка.
- Ручные слоты фиксируются и не сдвигаются автопланировщиком.
- Повторное планирование перестраивает только автоматические слоты.
- Сегодня / Неделя / Все задачи / Настройки.
- Создание, редактирование, удаление, завершение, ручное назначение времени и снятие времени.
- Поиск и фильтры задач.
- Рабочий график, обед, буфер между задачами и максимальный фокус-блок.
- Экспорт и импорт JSON.
- Локальное сохранение в localStorage.
- PWA manifest + service worker для установки на iPhone и офлайн-работы.
- Safe-area, нижняя iOS-навигация, sheet-окна и системный шрифт Apple.

## Как открыть на iPhone

Для установки как PWA сайт должен открываться по HTTPS (или с локального dev-сервера). В Safari: «Поделиться» → «На экран “Домой”». После установки Flowday открывается в standalone-режиме.

Для локального теста на компьютере достаточно любого статического web-сервера, например:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080` в браузере.

## Важное

Это веб/PWA-порт, а не подписанный `.ipa`/Xcode-проект. Для публикации в App Store нужен отдельный нативный контейнер или нативная SwiftUI-версия и стандартный процесс Apple Developer.
