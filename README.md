# Flowday

**Flowday** — персональный планировщик задач для iPhone в формате offline-first PWA. Он помогает превратить список дел в расписание: учитывает приоритет, дедлайн, длительность, рабочее время, перерыв и занятые вручную блоки.

## Возможности
- автоматическое планирование по свободным окнам;
- ручное назначение даты и времени;
- недельный обзор;
- библиотека задач с поиском и фильтрами;
- режим фокуса;
- статистика;
- светлая, тёмная и системная тема;
- локальное хранение без аккаунта и сервера;
- экспорт и импорт резервной копии;
- работа офлайн после первого открытия;
- обновление установленной версии через Service Worker.

## Быстрый запуск через GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. В `Settings → Pages` выберите `Deploy from a branch → main → /(root)`.
4. Откройте опубликованный HTTPS-адрес через Safari на iPhone.
5. Выберите `Поделиться → На экран «Домой»`.

## Обновление
Замените файлы репозитория файлами новой версии и сделайте commit. При следующем открытии/обновлении установленная PWA проверит новый Service Worker и предложит обновиться.

## Данные
Задачи и настройки хранятся локально в браузере устройства. GitHub Pages не получает содержимое ваших задач. Резервную копию можно экспортировать из `Ещё → Настройки`.

## Иконка
Исходник иконки — PNG 1024×1024. Инструкция: `docs/ICON_RU.md`.

## Структура
- `index.html` — интерфейс;
- `app.js` — логика и планировщик;
- `style.css` — оформление;
- `manifest.webmanifest` — PWA manifest;
- `sw.js` — offline cache и обновления;
- `assets/icons/` — иконки;
- `docs/` — инструкции;
- `tools/` — утилиты проекта.
