# Tavrimo

**Tavrimo — приложение для личного планирования.**

Tavrimo объединяет календарные события, личные задачи и инструменты фокусировки в одном пространстве. Приложение помогает увидеть план дня и недели, распределить задачи по времени и отслеживать собственную нагрузку.

Tavrimo создан как адаптивное веб-приложение (PWA): его можно открыть в браузере на компьютере или установить на главный экран смартфона.

## Для кого Tavrimo

Для тех, кто совмещает учёбу, работу и личные дела и хочет держать календарь и список задач в одном месте. Приложение не ограничивается одним сценарием: задачи можно распределять по категориям «Учёба», «Работа», «Личное», «Дом» и «Другое».

## Что доступно сейчас

### План дня
- Просмотр календарных событий и запланированных задач на выбранную дату.
- Выбор даты и переход к текущему дню.
- Список задач, которым ещё не назначено время.
- Индикатор загрузки дня и обзор занятого времени.

### Календарь недели
- Семидневный обзор с переходом между неделями.
- Просмотр событий и задач выбранного дня.
- Отображение продолжительности запланированной нагрузки.

### Задачи
- Создание, редактирование и удаление задач.
- Длительность от 15 минут до 4 часов.
- Три уровня приоритета.
- Категория, заметка, дата дедлайна и при необходимости время дедлайна.
- Ручное назначение даты и времени выполнения.
- Поиск и фильтры: все, открытые, запланированные, с дедлайном, без времени, просроченные и выполненные задачи.
- Отметка выполнения и контроль просроченных задач.

**Время задач пользователь назначает самостоятельно.** Tavrimo помогает видеть загрузку и проверять план, но не расставляет задачи по календарю автоматически.

### Импорт календаря
- Ручной импорт одного или нескольких файлов iCalendar (`.ics`) с экрана «Сегодня».
- Поддержка повторяющихся событий, часовых поясов, событий на весь день и многодневных событий.
- Импортированные события отображаются вместе с задачами в представлениях дня и недели.

Для обновления импортированного календаря нужно загрузить актуальный файл `.ics` повторно.

### Фокусировка
- Таймер фокус-сессии для выбранной задачи.
- Настраиваемая длительность по умолчанию: 25, 50, 90 или 120 минут.
- Сохранение истории завершённых фокус-сессий.

### Статистика и состояние плана
- Количество выполненных задач за неделю.
- Объём задач, запланированных на неделю.
- Время, проведённое в фокус-сессиях.
- Оценка загрузки и подсказки по состоянию плана.

### Профиль и настройки
- Локальное имя и фотография профиля.
- Настройка начала и конца рабочего дня.
- Настройка обеденного перерыва, временного резерва после задачи и длительности фокус-сессии.
- Возможность учитывать выходные дни.
- Повторный запуск вводного обучения.

### Резервные копии
- Экспорт данных Tavrimo в файл JSON.
- Импорт ранее созданной JSON-копии.
- Подтверждение перед заменой текущих данных при импорте.

## Как хранятся данные

Tavrimo работает по локальной модели хранения: задачи, настройки, календарные данные, история фокуса и профиль сохраняются в браузере на устройстве пользователя.

- Для использования не требуется создавать учётную запись.
- Автоматической синхронизации данных между разными устройствами нет.
- Для переноса данных на другое устройство используйте экспорт и импорт JSON.
- Импорт резервной копии заменяет текущий набор данных — перед ним рекомендуется сохранить отдельную копию.

После первого успешного открытия онлайн приложение кэширует свою оболочку и может повторно запускаться без сети. Для первой загрузки и установки требуется интернет.

## Текущие границы продукта

В текущей редакции:
- календарь пополняется файлами `.ics`, а не автоматически обновляемыми URL-подписками;
- автоматическое получение расписания университета не является действующей функцией;
- задачи планируются вручную;
- данные не синхронизируются через облачный аккаунт между устройствами.

Эти ограничения важно учитывать при использовании приложения.

Мы развиваем Tavrimo постепенно: сначала стабильные базовые сценарии планирования, затем улучшения интерфейса и новые возможности. В журнал изменений попадают существенные пользовательские изменения, а не каждый технический коммит.
