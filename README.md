# Tavrimo 12.0.7 — расписание РЭУ + планировщик

Tavrimo — iPhone-first offline-first PWA для студентов РЭУ им. Г.В. Плеханова. Главный экран — расписание группы. Задачи, дедлайны, Focus и статистика остаются частью того же личного дня и учитывают занятое учебное время.

## Главное

- расписание РЭУ на главном экране;
- выбор группы по номеру;
- автоматическая синхронизация через Tavrimo Sync Gateway;
- преподаватели, аудитории, типы занятий и время пар;
- ручное планирование задач без автоматического выбора времени;
- задачи можно привязать к конкретной паре;
- пары блокируют время при проверке ручных задач;
- локальное хранение и работа офлайн;
- импорт `.ics` остаётся резервным способом;
- светлая, тёмная и системная тема;
- onboarding для первого запуска.

## Источник расписания

Основной live-источник Tavrimo — официальный портал РЭУ: https://rasp.rea.ru/. Автоматическая загрузка использует отдельный Sync Gateway, который обращается к порталу; Gateway не является официальным сервисом РЭУ. В текущей демонстрационной сборке для группы `15.14Д-ГГ04/266` временный ICS-снимок из календарной ленты Vuzio встроен непосредственно в клиентский `app.js`: он содержит 46 занятий за период 9–23 ноября 2026 года, показывается без обращения к Sync Gateway и доступен офлайн. Для остальных групп сохраняется прежний Sync Gateway. Прямое live-получение с `rasp.rea.ru` сейчас не подтверждено из-за наблюдавшегося HTTP 403.

## Запуск

Для PWA нужен HTTPS. Для автоматической загрузки и обновления расписания нужен Tavrimo Sync Gateway. Самый простой релизный вариант — развернуть весь репозиторий одним Docker-контейнером: PWA и `/api/rea/schedule` будут работать на одном адресе. Для GitHub Pages можно оставить фронтенд на GitHub, а Gateway разместить отдельно и прописать его URL в `config.js`.

Для демонстрационной группы `15.14Д-ГГ04/266` приложение загружает встроенный ICS-снимок из `app.js` даже без сети и сохраняет события в браузере. Для групп без статического снимка остаётся прежняя проверка через Sync Gateway: при запуске, возвращении из фона и далее раз в 15 минут, пока приложение открыто и есть интернет. Live-доступ к РЭУ в текущей среде всё ещё может завершаться HTTP 403; в этом случае сохранённое расписание не должно теряться.

Резервный `.ics` импорт находится внутри «Расписание РЭУ → Импорт .ics вручную» и нужен только на случай временной недоступности Gateway/портала.

## Данные

Задачи, настройки и локально загруженное расписание хранятся в браузере пользователя. На сервер Sync Gateway передаётся только номер запрошенной группы и технические запросы к официальному порталу; сервер не нужен для офлайн-просмотра уже загруженного расписания.

## История обновлений

Если Render возвращает `502`, сначала обновите gateway до актуального релиза и проверьте его логи. В релизе 12.0.9 поиск выполняется через основную страницу `rasp.rea.ru` и её обычное поле; прямой переход `?q=` оставлен резервным способом. Релиз 12.0.10 синхронизирует CI-проверки с текущими файлами. Реальная синхронизация должна быть отдельно проверена после развёртывания на Render.

## 12.0.5 hotfix

Эта версия исправляет ручное обновление расписания и поиск группы на `rasp.rea.ru`. После обновления GitHub Render должен автоматически задеплоить новый commit. Если используете установленный PWA, откройте сайт один раз онлайн — новая версия `app.js` имеет cache-busting `?v=12.0.5`.


## 12.0.7 hotfix

Ручная кнопка «Обновить» теперь принудительно обходит серверный TTL-кэш и отправляет запрос с `force=1`. Поиск группы РЭУ выбирает режим «Группы», умеет работать с кнопкой поиска, `<select>`/listbox и нормализует регистр/дефисы/пробелы. Ошибка синхронизации больше не выглядит как «молчаливая» кнопка: интерфейс показывает «Обновляю…» и после ошибки — «Повторить».

## Последнее обновление интерфейса

В версии 12.1.0 представлен редизайн Campus Utility / Editorial Planner. Он меняет визуальное оформление, но сохраняет существующую логику расписания и задач.


## Импорт ICS из настроек (12.1.5)

В разделе «Настройки → Данные → Импортировать» доступны оба типа файлов: `.json` для резервной копии Tavrimo и `.ics` для расписания занятий. Приложение определяет тип файла автоматически. Импорт ICS обновляет только календарь выбранной группы и не заменяет задачи, настройки или статистику. После ручного импорта календарь остаётся локальным, поэтому недоступность `rasp.rea.ru` не приводит к повторяющимся ошибкам 403.

## Локальные снимки расписания (12.1.5)

Для группы `15.14Д-ГГ04/266` в `data/schedules/` уже включён проверенный календарный снимок. Tavrimo загружает его автоматически, прогоняет через текущий парсер и календарь, затем сохраняет события локально для офлайн-доступа. Для групп без снимка продолжает работать прежний Sync Gateway. Снимок маркируется как демонстрационный и не выдаётся за live-синхронизацию. См. `data/schedules/README_RU.md` и `RELEASE_NOTES_12.1.5_RU.md`.
