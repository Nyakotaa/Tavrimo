# Tavrimo 12.0.2 — расписание РЭУ + планировщик

Tavrimo — iPhone-first offline-first PWA для студентов РЭУ им. Г.В. Плеханова. Главный экран — расписание группы. Задачи, дедлайны, Focus и статистика остаются частью того же личного дня и учитывают занятое учебное время.

## Главное

- расписание РЭУ на главном экране;
- выбор группы по номеру;
- автоматическая синхронизация через Tavrimo Sync Gateway;
- преподаватели, аудитории, типы занятий и время пар;
- ручное планирование задач без автоматического выбора времени;
- задачи можно привязать к конкретной паре;
- пары блокируют время при проверке ручных задач;
- локальное хранение и работа офлайн;
- импорт `.ics` остаётся резервным способом;
- светлая, тёмная и системная тема;
- onboarding для первого запуска.

## Источник расписания

Источник учебного расписания — официальный портал РЭУ: https://rasp.rea.ru/. На нём можно искать расписание по названию/номеру группы и выгружать календарь. Сам портал предупреждает, что экспортированные данные со временем могут перестать соответствовать актуальному расписанию, поэтому в приложении автоматически обновляется новый экспорт, а при спорных изменениях следует сверяться с официальным порталом.

Автоматическая загрузка Tavrimo использует отдельный Sync Gateway, который получает данные с официального портала. Gateway не является официальным сервисом РЭУ.

## Запуск

Для PWA нужен HTTPS. Для автоматической загрузки и обновления расписания нужен Tavrimo Sync Gateway. Самый простой релизный вариант — развернуть весь репозиторий одним Docker-контейнером: PWA и `/api/rea/schedule` будут работать на одном адресе. Для GitHub Pages можно оставить фронтенд на GitHub, а Gateway разместить отдельно и прописать его URL в `config.js`.

После ввода группы приложение само запрашивает актуальный экспорт с официального портала. Проверка выполняется при запуске, возвращении из фона и далее раз в 15 минут, пока приложение открыто и есть интернет. После изменения расписания новая версия сравнивается с локальной, а задачи с конфликтами возвращаются во входящие. Если iOS полностью выгрузил PWA, следующий запуск снова делает проверку.

Резервный `.ics` импорт находится внутри «Расписание РЭУ → Импорт .ics вручную» и нужен только на случай временной недоступности Gateway/портала.

## Данные

Задачи, настройки и локально загруженное расписание хранятся в браузере пользователя. На сервер Sync Gateway передаётся только номер запрошенной группы и технические запросы к официальному порталу; сервер не нужен для офлайн-просмотра уже загруженного расписания.

## 12.0.3: REA Sync Resilience

Если Render возвращал `502`, хотя расписание группы уже отображалось на rasp.rea.ru, обновите контейнер до 12.0.3. Gateway теперь не зависит от одного способа экспорта iCalendar: он также умеет забрать клиентский Blob/data download, обнаружить export-ресурс и разобрать уже отрисованную таблицу расписания в iCalendar.

Официальный источник расписания: https://rasp.rea.ru/.
