# Локальные снимки расписания Tavrimo

Папка предназначена для настоящих iCalendar-файлов `.ics`, которые публикуются вместе с приложением. Клиент загружает снимок автоматически по выбранному номеру группы, затем использует существующий календарь и локальное сохранение.

## Подключение файла

1. Сохраните проверенный ICS-файл в этой папке. Используйте простое имя латиницей, например `15.14D-GG04-266.ics`.
2. Добавьте в `manifest.json` запись в массив `snapshots`:

```json
{
  "groupCode": "15.14Д-ГГ04/266",
  "file": "data/schedules/15.14D-GG04-266.ics",
  "revision": "2026-11-09-v1",
  "capturedAt": "2026-11-09T12:00:00+03:00",
  "source": "Vuzio · календарный снимок",
  "minimumEvents": 1
}
```

3. Увеличьте `revision`, когда заменяете файл. Это заставляет браузер и Service Worker запросить новую версию.
4. Не помещайте в GitHub секретную URL-ленту или токен. Публикуется только содержимое `.ics`.

## Безопасность и полнота

- Сопоставление `groupCode` → `file` задаётся явно; пользовательский ввод никогда не превращается в путь к файлу.
- Файл должен содержать полный `VCALENDAR` и все ожидаемые `VEVENT`. Неподдерживаемые повторения, отмены, часовые пояса и события, которые текущий парсер пропускает, блокируют замену расписания.
- Для строгой проверки семестрового диапазона добавьте `coverageStart` и `coverageEnd` в формате `YYYY-MM-DD`, а также `minimumEvents`.
- В интерфейсе такой источник обозначается как демонстрационный снимок, а не как live-синхронизация.
- Отсутствие записи для группы не отключает обычный Sync Gateway: используется прежний live-механизм.


## Включённый демонстрационный снимок

Для группы `15.14Д-ГГ04/266` календарь также встроен прямо в `app.js` как автономный fallback. Это намеренное дублирование небольшого ICS-файла: оно гарантирует показ расписания, даже если хостинг не отдаёт `data/schedules/manifest.json` или Sync Gateway отвечает 503. Файл в этой папке сохраняется как отдельный исходный артефакт и для будущего расширения каталога.

`rea-15-14d-gg04-266.ics` — календарная лента Vuzio для выбранной в приложении группы `15.14Д-ГГ04/266`. В файле 46 занятий с 9 по 23 ноября 2026 года включительно. Снимок сформирован 9 ноября 2026 года в 10:19 (московское время), согласно `DTSTAMP` исходной ленты.

**Ограничения:** этот файл покрывает только период 9–23 ноября, а не весь семестр. Дальнейшие изменения в Vuzio/РЭУ автоматически в репозиторий не попадут. В `X-WR-CALNAME` исходной ленты последняя часть номера выглядит как `26б` (кириллическая «б»), тогда как выбранная пользователем группа и запись Tavrimo — `266`; это отображённое название источника сохранено и проверяется отдельно от ключа группы. `PRODID` прямо указывает Vuzio — не обозначайте этот снимок как прямой официальный экспорт РЭУ.

Не публикуйте URL ленты с секретным токеном. В репозитории хранится только содержимое календаря. После демонстрации замените статический снимок разрешённой live-интеграцией и уберите/обновите запись этой группы в `manifest.json`.
