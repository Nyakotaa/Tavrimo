# Tavrimo 12.1.2 — REA 403 diagnostics

## Зачем нужен этот выпуск

По журналам опубликованного Sync Gateway подтверждено, что `rasp.rea.ru` возвращает серверу Tavrimo HTTP 403 Forbidden с телом `403 Forbidden nginx`. Страница поиска и поле ввода при этом не загружаются (`inputCount=0`). Это не ошибка номера группы и не проблема DOM-селектора.

## Изменения

- Сервер проверяет HTTP-статус основного ответа портала до поиска элементов.
- При HTTP 403 автоматизация прекращает попытки поиска, перезагрузки и перехода по `?q=`.
- После 403 вводится пятиминутная пауза для повторных обращений к порталу; сервер отправляет `Retry-After`.
- Клиент показывает отдельное сообщение о запрете со стороны `rasp.rea.ru`.
- Уже сохранённое расписание не удаляется и не заменяется ошибочным ответом.
- Добавлен тест классификации 403 и проверки пользовательского сообщения.

## Важное ограничение

Этот выпуск не обходит ограничения портала и сам по себе не восстанавливает автоматический доступ с Render. Для этого требуется разрешённый способ интеграции, изменение политики доступа со стороны РЭУ либо другой согласованный источник. До этого доступен ручной импорт официального `.ics`.

## Проверки

Локальные проверки подтверждают корректную обработку HTTP 403, код ошибки, cooldown, синтаксис и сохранение пользовательского расписания при неудачной синхронизации. Доступ Render к реальному порталу остаётся непроверенным до повторного развёртывания и теста на опубликованном сервисе.
