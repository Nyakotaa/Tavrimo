# Обновление существующего репозитория Tavrimo до 12.2.0 (Windows)

## Перед обновлением

1. Открой текущую опубликованную веб-версию Tavrimo и зайди в «Ещё → Настройки → Данные → Экспортировать».
2. Сохрани JSON backup в отдельную папку. Не отправляй резервную копию в публичный репозиторий: в ней могут быть личные задачи.
3. В GitHub Desktop убедись, что в старом репозитории `Tavrimo` нет незакоммиченных пользовательских изменений. Если есть — сначала сохрани их отдельным коммитом или сделай копию папки.

## Обновление через GitHub Desktop

1. Скачай `Tavrimo_Web_12.2.0_Spotify_Dark_UI.zip` и распакуй его.
2. В GitHub Desktop выбери существующий репозиторий `Tavrimo` (не `Tavrimo-iOS`).
3. Через `Repository → Show in Explorer` открой локальную папку существующего репозитория.
4. В распакованной папке `Tavrimo_Web_12.2.0_Spotify_Dark_UI` выдели всё содержимое (`Ctrl+A`, `Ctrl+C`).
5. Вставь содержимое в локальную папку репозитория `Tavrimo` (`Ctrl+V`) и согласись на замену файлов.
6. Проверь изменения в GitHub Desktop. Важно: в списке должны появиться `spotify-dark.css`, `assets/branding/tavrimo-cup-mark.png` и release-документы `12.2.0`.
7. В поле Summary введи `Release Tavrimo 12.2.0 - Spotify-inspired Dark UI`.
8. Нажми `Commit to main`, затем `Push origin`.
9. Дождись публикации GitHub Pages/Render, открой приложение онлайн и перезагрузи страницу. При установленном PWA закрой приложение полностью и открой снова, чтобы обновился Service Worker.

## После обновления

- Проверь, что в разделе «Ещё» отображается версия `v12.2.0`.
- Проверь, что интерфейс стал тёмным, а в центре верхней панели появился логотип чашки Tavrimo.
- Проверь, что существующие задачи и расписание сохранились.
- Для проверки резервной копии импортируй ранее экспортированный JSON только при необходимости и после подтверждения приложения.

## Важное замечание о версии исходников

Пакет 12.2.0 собран на базе web source 12.1.6 из handoff-архива от 23.11.2026. Перед заменой файлов убедись в GitHub Desktop, что в текущем репозитории нет более новых изменений, которых нет в этом пакете. Не обновляй из этого архива отдельный репозиторий `Tavrimo-iOS`.
