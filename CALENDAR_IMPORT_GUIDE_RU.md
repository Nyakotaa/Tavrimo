# Локальный импорт календаря в Tavrimo 12.4.0

## Что поддерживается

- Импорт одного или нескольких файлов `.ics` с устройства.
- Повторяющиеся события (DAILY, WEEKLY, MONTHLY, YEARLY), часовые пояса, all-day и multi-day события.
- Сохранение календаря локально для дальнейшей работы офлайн.
- Несколько импортированных файлов отображаются вместе с бывшим расписанием РЭУ в одной неделе.
- Повторный импорт того же файла обновляет соответствующий локальный источник, а не создаёт новый календарь.

## Как импортировать

1. Открой экран «Сегодня».
2. Нажми «Импортировать .ics».
3. Выбери файл календаря в приложении «Файлы» (iPhone) или файловом менеджере (Android).
4. После завершения импорта события появятся на Today и Week.

Чтобы обновить календарь, экспортируй новый файл `.ics` из исходного приложения и импортируй его снова.

## Миграция со старой версии

При первом запуске 12.4.0 приложение переносит сохранённые пары РЭУ в локальный календарь, сохраняет исходные ID событий и связи задач. Скачанные ранее события Google/Outlook/iCloud сохраняются как локальные снимки; секретные URL лент очищаются. Автоматических запросов к расписанию и feed-ссылкам больше нет.

Имя и аватар профиля, задачи, статистика и календарные события остаются в локальных данных. Фото не отправляется на сервер. Для резервной копии используй «Ещё → Настройки → Экспортировать».
