# Подключение календарей в Tavrimo 12.3.0

## Что поддерживается

- Импорт одного или нескольких файлов `.ics` из Apple Calendar, Google Calendar, Outlook и других приложений, поддерживающих iCalendar. Файл — снимок на момент экспорта; чтобы получить изменения, импортируй обновлённый файл.
- Read-only подписка по HTTPS iCalendar URL для Google Calendar, Outlook и iCloud. Tavrimo обновляет ссылку при запуске/возврате в приложение и примерно раз в 30 минут, пока PWA открыта и есть интернет. Провайдер может обновлять опубликованный feed с собственной задержкой.
- Внешние источники хранятся отдельно от календаря РЭУ. Их события отображаются в «Сегодня» и «Мой план», влияют на загрузку и блокируют пересекающиеся ручные слоты. События `TRANSPARENT` показываются, но не блокируют время.
- Последний успешный снимок хранится локально и доступен офлайн.

## Где получить iCalendar ссылку

### Google Calendar

Открой Google Calendar в браузере → Settings → выбери нужный календарь → Integrate calendar → Secret address in iCal format. Секретная ссылка предоставляет read-only доступ; не публикуй её. Если ссылка стала известна другим, сбрось её в настройках Google Calendar.

Официальная справка: https://support.google.com/calendar/answer/37648

### Outlook / Outlook.com / Microsoft 365

Открой Calendar settings → Shared calendars → Publish a calendar. Выбери календарь и разрешённую детализацию, нажми Publish, затем скопируй ICS link. Ссылка доступна только для чтения. Частота обновления зависит от приложения/провайдера, который подписался на календарь.

Официальная справка: https://support.microsoft.com/en-us/outlook/share-your-calendar-in-outlook-on-the-web

### Apple iCloud Calendar

В приложении Calendar открой список календарей → нажми кнопку информации рядом с нужным iCloud calendar → включи Public Calendar → Share Link. Любой, у кого есть ссылка, сможет читать этот календарь. Для приватного календаря используй экспорт `.ics`, если он доступен в твоём способе работы.

Официальная справка: https://support.apple.com/guide/iphone/share-icloud-calendars-iph7613c4fb

## Как подключить в Tavrimo

1. Открой «Ещё» → «Мои календари».
2. Для файла нажми «Импортировать .ics-файл» и выбери один или несколько файлов.
3. Для живой ссылки вставь имя (необязательно) и HTTPS iCalendar URL, затем нажми «Подключить календарь».
4. В списке можно скрыть календарь, обновить ссылку или удалить источник.

## Приватность и технические границы

- Tavrimo не входит в аккаунты Google/Microsoft/Apple, не просит пароль и не использует OAuth.
- Подписки read-only: события нельзя редактировать из Tavrimo и изменения не отправляются обратно провайдеру.
- Секретный feed URL хранится локально в данных браузера и включается в JSON backup. Считай резервные копии с такими ссылками конфиденциальными.
- Для URL-подписок нужен обновлённый Sync Gateway с `POST /api/calendar/feed`. Gateway запрашивает только разрешённые HTTPS-хосты и проверяет перенаправления; feed URL и ICS body не сохраняются в persistent storage или логах.
- При ошибке провайдера Tavrimo сохраняет последний успешный снимок и показывает ошибку обновления.
- Поддерживаются распространённые RRULE: DAILY/WEEKLY/MONTHLY/YEARLY. Сложные исключения, отдельные изменения экземпляров и нестандартные VTIMEZONE могут отображаться не полностью.
- Импорт `.ics`-файла работает без Gateway; URL-подписки — нет.
