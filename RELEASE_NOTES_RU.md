# Flowday 7.0.0

Релиз сфокусирован на том, чтобы планировщик действительно исполнял параметры задачи, а не только показывал их в интерфейсе.

## Исправлено
- дедлайн теперь влияет на фактическое окно автопланирования;
- добавлено необязательное точное время дедлайна;
- просроченный дедлайн корректно определяется даже внутри текущего дня;
- процент занятости считается по реально запланированной длительности;
- начало и конец слота отображаются явно;
- ручные слоты проверяют дату, рабочие часы, перерыв, дедлайн, прошедшее время и конфликты;
- изменение длительности, приоритета или дедлайна запускает перепланирование автоматических задач;
- перевод ручной задачи обратно в автоматическую схему возвращает её планировщику;
- обновлённые настройки рабочего дня пересобирают автоматический план;
- обновлена иконка и `apple-touch-icon` для iPhone;
- Service Worker поднят до `flowday-v7.0.0`.

## Важная деталь
Дедлайн сам по себе не является занятым временем. Он ограничивает диапазон, в который задача может быть поставлена. После сохранения автоматической задачи Flowday должен выделить реальный слот; именно этот слот увеличивает процент занятости.
