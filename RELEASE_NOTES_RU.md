# Tavrimo 12.0.5 — Refresh + REA Sync Fix

- Исправлена кнопка ручного обновления расписания: она больше не блокируется из-за фонового запроса и имеет delegated click handler.
- Ручное обновление не зависит от `navigator.onLine`.
- `app.js`, `style.css` и `config.js` получают cache-busting версию.
- Service Worker использует network-first для JS/CSS/config/manifest, чтобы после деплоя не оставался старый код.
- Sync Gateway больше не блокирует Service Worker официального портала РЭУ.
- Перед поиском группы портал обновляется, затем поиск отправляется через кнопку/Enter; результат выбирается только после появления реального расписания.
