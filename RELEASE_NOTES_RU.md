# Tavrimo 11.0.0 — Расписание РЭУ

Большое обновление превращает Tavrimo из обычного планировщика задач в студенческий планировщик, где университетское расписание становится частью ежедневного плана.

## Новое

- подключение группы РЭУ через официальный экспорт `.ics`;
- пары с преподавателем, аудиторией, временем и типом занятия;
- единая повестка дня: пары + задачи;
- пары блокируют конфликтующие ручные задачи;
- пары входят в расчёт загрузки дня;
- задача может быть привязана к конкретной паре;
- стабильные ID событий сохраняют привязки при повторном импорте;
- безопасная обработка дубликатов и повреждённых календарных событий;
- нормализация UTC-дат в московское время;
- защита от случайного смешивания расписаний разных групп.

## Важно

Официальный портал РЭУ остаётся источником расписания. Tavrimo не обещает live-синхронизацию: после изменения расписания новый `.ics` нужно импортировать повторно.
