# Tavrimo 12.0.10 — актуализация проверок релиза

- Сохранён порядок поиска группы из 12.0.9: сначала обычная страница `https://rasp.rea.ru/` и видимое поле поиска, прямой `?q=` — резервный способ.
- Исправлены устаревшие проверки GitHub Actions: теперь они сверяются с актуальной версией и иконкой `apple-touch-icon-v17.png`.
- Исправлены тестовые даты, которые раньше оказывались в прошлом и из-за этого давали ложные ошибки при последующих запусках.
- Уточнены проверки fallback-парсера в соответствии с текущими диагностическими маркерами.

**Важно:** локальные проверки не подтверждают реальную синхронизацию на Render. После публикации нужно повторить синхронизацию в Tavrimo и проверить логи сервера.

# Tavrimo 12.0.7 — REA Sync Refresh Fix

## Исправления

- Кнопка «Обновить» на главном экране и в настройках получает прямой click-handler и всегда отправляет принудительный запрос.
- Принудительное обновление добавляет `force=1` и обходит 5-минутный кеш Sync Gateway.
- При активной синхронизации повторное ручное обновление отменяет старую попытку и запускает новую.
- После ошибки кнопка меняется на «Повторить», а причина остаётся видимой.
- Поиск группы РЭУ теперь явно выбирает «Группы», нажимает поиск, поддерживает icon-only search и варианты `<select>`/listbox.
- Сопоставление группы нормализует регистр, `ё/е`, пробелы и типографские дефисы.
- Портал РЭУ не обновляется до выбора группы, чтобы не сбрасывать поисковое состояние.
- Service Worker портала РЭУ не блокируется.
- Исправлена PWA-иконка: HTML, Service Worker и GitHub Actions используют `apple-touch-icon-v16.png`.
