# Tavrimo 12.0.0 — Расписание РЭУ + Live Sync

Tavrimo превращает расписание РЭУ в основу ежедневного планирования. Пользователь указывает номер группы один раз, после чего приложение само получает официальный календарный экспорт, показывает пары на главном экране и использует учебное время как занятое.

## Автоматическая синхронизация
- при сохранении группы;
- при запуске приложения;
- при возвращении из фона;
- каждые 15 минут, пока приложение открыто и есть интернет;
- через ETag повторно скачивается только изменившийся календарь.

## Надёжность
- изменение времени, даты, преподавателя, аудитории, типа или предмета обнаруживается при следующей проверке;
- связанные задачи сохраняют привязку, когда событие можно однозначно сопоставить;
- если обновлённая пара заняла время ручной задачи, задача возвращается во входящие;
- пустой/неполный ответ не стирает последнее известное расписание автоматически.

## Ограничение
Live Sync не является прямым API РЭУ и не является официальным сервисом университета. Gateway получает данные через официальный пользовательский интерфейс и экспорт календаря. При расхождении следует сверяться с `https://rasp.rea.ru/`.
