# Flowday 6.0.0

Первая релизная полировка интерфейса.

Главное изменение — приложение стало спокойнее: меньше кнопок, меньше информационного шума, понятнее назначение каждого действия. Создание задачи осталось только в центральной кнопке `+`.

Выбор даты на главной теперь работает через отдельное окно. Планирование вынесено в собственное короткое окно, где доступны только две полезные операции: перестроить план и снять автоматические слоты.

Из раздела «Ещё» удалены встроенные инструкции по работе алгоритма, установке на iPhone и офлайн-режиму: для этого используется документация проекта и Telegram.

В этой версии также обновлены цвета, тёмная тема, анимации, проверки ручного времени, миграция локальных данных и обновление Service Worker.
