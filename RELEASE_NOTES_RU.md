# Flowday 8.0.0 RC2

Вторая release-candidate версия после углублённого QA. Основная цель — сделать планировщик устойчивым к конфликтам, неполному/повреждённому импорту и ручному планированию.

## Главное
- deadline-safe автопланирование;
- ручной буфер не пересекает обед;
- уникальные ID при импорте;
- корректная обработка задач без дедлайна;
- безопасная ремонтная миграция конфликтующих ручных слотов;
- выполненные задачи больше не получают статус «Просрочено»;
- Focus корректно привязан к дате начала;
- экспорт даёт обратную связь при отмене.

## Проверка перед финалом
Запусти `node tools/test_scheduler.mjs`, затем открой PWA на iPhone с интернетом один раз и протестируй обновление RC1 → RC2, иконку, offline и Focus при блокировке экрана.
