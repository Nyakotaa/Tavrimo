# Flowday v5.0.0

## Что нового

Flowday 5 — это полировка перед публичным использованием: чистый первый запуск, более спокойный интерфейс и более предсказуемое планирование.

### Главное

- чистый старт без чужих задач;
- автоматический планировщик с учётом рабочих дней;
- ручные блоки остаются на месте;
- более аккуратная валидация времени;
- обновлённый офлайн-режим;
- уведомление о новой версии внутри PWA;
- отдельная инструкция установки на iPhone;
- отдельная инструкция для иконки;
- отдельная инструкция публикации и обновления GitHub Pages.

## Перед релизом

Проверь:

- ссылку GitHub Pages;
- установку через Safari;
- запуск в авиарежиме;
- создание и завершение задачи;
- автопланирование;
- ручной слот;
- экспорт/импорт;
- смену темы;
- работу иконки после переустановки на экран «Домой».
