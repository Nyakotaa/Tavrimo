# Flowday 9.1.0 Final

## Главное
Flowday теперь полностью ручной в части времени. Приложение не выбирает слот само и не перестраивает расписание без команды пользователя.

## Новые правила
- при создании задачи можно сразу указать дату и время вручную;
- можно сохранить задачу без времени и назначить его позже;
- нельзя указать только дату или только время;
- дедлайн ограничивает допустимый слот;
- длительность определяет фактическую длину блока;
- резерв учитывается при проверке конфликтов и загрузке дня;
- приоритет влияет на порядок задач и визуальный акцент, но не меняет вручную выбранное время;
- существующие запланированные задачи из прошлых версий считаются ручными.
