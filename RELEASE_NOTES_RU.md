# Tavrimo 10.0.0

## Новое
- Новое имя приложения: Tavrimo.
- Интерактивное обучение при первом запуске с подсветкой основных элементов.
- Обучение можно пропустить и повторно открыть из настроек.
- Вся пользовательская документация и GitHub-метаданные переведены на новое название.
- Сохранена миграция старых локальных данных.
- Обновлён Service Worker и набор иконок.

## UX
- Обучение не добавляет новые постоянные кнопки в основной интерфейс.
- После завершения оно исчезает и не мешает работе приложения.
