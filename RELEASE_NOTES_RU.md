# Flowday 8.0.0 Release Candidate

## Цель RC
Закрыть функциональные дефекты из QA-аудита 7.0.0 и подготовить приложение к финальному регрессионному прогону.

## Исправлено
- **Перепланирование:** глобальное действие всегда пересобирает автоматические задачи от сегодняшнего дня. Выбранная дата влияет только на просмотр, а не на границу глобального алгоритма.
- **Ручной режим:** выполнение/возврат не сбрасывают ручной режим, пока сохранённый слот остаётся валидным.
- **Возврат просроченной задачи:** если старое время уже прошло или больше не соответствует настройкам, задача возвращается во входящие и снова доступна автопланировщику.
- **Focus:** отсчёт основан на `Date.now()`, а не на количестве срабатываний таймера. Сессия продолжается при сворачивании приложения.
- **Статистика:** все карточки и Focus теперь относятся к одной и той же выбранной неделе.
- **Импорт:** битые даты/время, неверные типы и неполные слоты нормализуются безопасно.
- **Приоритет:** отдельный вес влияет на очередь внутри допустимого диапазона, но никогда не нарушает жёсткий дедлайн.
- **Буфер:** резерв учитывается при размещении и в процентах загрузки дня.
- **Календарь:** добавлена навигация по неделям.
- **Sheets:** устранена гонка при быстром закрытии и открытии одного окна.
- **Offline/online:** приложение сообщает о потере и восстановлении соединения.
- **Accessibility:** добавлена понятная aria-label для поиска задач.

## Перед финальным релизом
Рекомендуется:
1. Залить RC1 на GitHub Pages.
2. Обновить установленную PWA на iPhone через интернет.
3. Пройти чек-лист `docs/RELEASE_CHECKLIST_RU.md`.
4. Проверить иконку после удаления/повторного добавления Web App на экран «Домой».
5. Провести финальный ручной тест на реальном iPhone.
