# Tavrimo — дневник разработки

Дневник фиксирует развитие продукта с точки зрения пользователя: зачем существует функция, какую задачу она решает и что меняется в приложении. Внутренние коммиты, технические проверки и промежуточные сборки остаются в истории Git.

## Запись 001. Первая функциональная редакция

**25 ноября 2026 года**

На этой точке Tavrimo оформляется как приложение для личного планирования. Основная задача продукта — собрать календарные события, список дел и работу с фокусом в одном понятном интерфейсе.

### Основные сценарии

**План на день и неделю**

Пользователь может выбрать дату, увидеть события календаря и задачи, перейти к недельному обзору и оценить предстоящую нагрузку. Задачи без назначенного времени остаются в отдельном списке, поэтому их можно распределить позже.

**Ручное планирование задач**

Для каждой задачи задаются название, длительность, приоритет, категория, дедлайн и заметка. Пользователь сам выбирает дату и время выполнения. Такой подход сохраняет контроль над расписанием за человеком: приложение показывает занятость и помогает заметить перегрузку, но не принимает решение о переносе дел самостоятельно.

**Импорт календаря**

События можно добавить из файлов iCalendar (`.ics`). Парсер поддерживает повторения, часовые пояса, события на весь день и многодневные события. После импорта календарные события становятся частью общего представления дня и недели.

**Фокус и статистика**

Таймер помогает выделить время для одной выбранной задачи. История сессий и данные о выполнении задач используются в недельной статистике.

**Локальный профиль и данные**

Имя, фотография, задачи, настройки, календарь и история фокуса сохраняются на устройстве. Для резервного копирования предусмотрены экспорт и импорт JSON.

### Принципы первой редакции

1. **Единое пространство.** Календарь и задачи рассматриваются вместе, а не как независимые списки.
2. **Ручной контроль.** Пользователь определяет, когда выполнять задачу.
3. **Локальное хранение.** Основные данные находятся на устройстве, без обязательной регистрации.
4. **Понятный интерфейс.** День, неделя, задачи, фокус и настройки разделены на самостоятельные разделы.
5. **Постепенное развитие.** В журнал попадают реальные изменения доступных пользователю сценариев.

### Текущие ограничения

Первая описываемая редакция не включает облачную синхронизацию между устройствами, автоматическое обновление календарей по URL и автоматическое составление расписания задач. Файлы календаря импортируются вручную; для переноса данных используется JSON-резервная копия.
