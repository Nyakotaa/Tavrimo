# Tavrimo 12.1.0 — Campus Editorial Redesign

## Что изменено

- Введена визуальная система Campus Utility / Editorial Planner с графитово-зелёной палитрой, тёплым текстом и лаймовыми функциональными акцентами.
- Логотип TAVRIMO выровнен по центру верхней панели; контекст текущего экрана остаётся справа.
- Главный экран получил более лёгкую структуру: компактный блок источника расписания, более читаемые строки занятий и задач, уменьшено количество декоративных поверхностей.
- Увеличена читаемость текста на основных мобильных экранах.
- Нижняя навигация, раздел «Ещё», поиск и действия синхронизации переведены на согласованные SVG-иконки.
- Освежено оформление недельного календаря, списка задач, пустых состояний и основных форм.
- Сохранены существующие идентификаторы элементов, обработчики событий, модель задач, PWA-механика и API синхронизации.
- Обновлены версии ресурсов и кэш Service Worker для корректного получения новой оболочки приложения.

## Что важно знать

Этот релиз посвящён редизайну. Он не включает исправление известной ошибки 502 при синхронизации с порталом РЭУ и не является подтверждением живой синхронизации. Эти вопросы требуют отдельной технической проверки.

## Проверки

- Синтаксическая проверка app.js и sw.js.
- Проверки логики планирования и расписания из доступного набора тестов.
- Проверка наличия DOM-идентификаторов, на которые ссылается JavaScript.
- Проверка manifest и целостности ZIP.
- Проверены структура DOM, существование идентификаторов, синтаксис и ключевые CSS/PWA-ресурсы. Перед публикацией рекомендуется дополнительно проверить экраны в браузере на реальном смартфоне.
