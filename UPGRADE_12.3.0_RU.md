# Обновление Tavrimo до 12.3.0

1. Сделай резервную копию текущего проекта и пользовательских данных.
2. Загрузить все содержимое релизного архива в отдельную ветку.
3. Проверить `VERSION` = `12.3.0`, наличие `calendar-update.css`, `sync-service/calendar-feed.mjs` и обновлённого `sync-service/server.mjs`.
4. Запустить `node tools/run_regression.mjs` в локальной среде Node.js 20+; для сервера также установить зависимости из `sync-service/package.json` и запустить `npm test` из этой папки.
5. После merge в `main` дождаться публикации GitHub Pages.
6. Отдельно убедиться, что Render Sync Gateway развернул новый backend с маршрутом `POST /api/calendar/feed`. Без этого внешние URL-подписки работать не будут; импорт файлов `.ics` продолжит работать без gateway.
7. На устройстве обновить PWA (Ctrl+F5 на компьютере; на телефоне закрыть и открыть установленный PWA/обновить страницу).

Не удаляй `tavrimo-planner-v17`: схема хранения не менялась, миграция данных не требуется.
