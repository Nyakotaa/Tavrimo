# Tavrimo 12.0.10 — актуализация проверок релиза

## Что изменено

- Сохранён search-first поток синхронизации РЭУ из 12.0.9: сначала основная страница портала и её видимое поле поиска, переход через `?q=` остаётся резервным вариантом.
- Приведён GitHub Actions к текущей версии: теперь workflow проверяет актуальную иконку `apple-touch-icon-v17.png` и запускает regression tests 12.0.10 вместо устаревших проверок 12.0.6.
- Исправлены тестовые даты ручного планирования и расписания, которые после наступления реального календарного дня ошибочно начинали считаться прошедшими.
- Обновлены проверки fallback-парсера и версии приложения, Service Worker и gateway package до версии релиза.

## Проверки

Локально прошли синтаксические проверки `app.js`, `sw.js` и `sync-service/server.mjs`, регрессионные тесты ручного планирования и университетского расписания, onboarding, проверки fallback-парсера, статические проверки синхронизации и проверка PWA-ресурсов.

**Не подтверждено:** живая синхронизация через опубликованный Render и актуальный портал РЭУ. После развёртывания нужно нажать «Повторить» в Tavrimo и проверить серверные логи.

## Обновление

1. Распакуйте архив и обновите содержимое `personal-planner` в корне GitHub-репозитория.
2. Сделайте commit в `main` и убедитесь, что GitHub Actions завершился успешно.
3. Убедитесь, что Render использует этот commit; при необходимости выполните Manual Deploy → Deploy latest commit.
4. После статуса Live откройте Tavrimo и повторите синхронизацию.
5. Если возникает ошибка, сохраните строки логов с префиксами `[REA_SEARCH_INPUT_RETRY]`, `[REA_SEARCH_INPUT_MISSING]`, `[REA_SEARCH_STATE]` и `[REA_SYNC_502]`.
