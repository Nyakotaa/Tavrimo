# Changelog

## 8.0.0-rc.2 — Release Candidate 2
- Планировщик стал deadline-safe: приоритет влияет на порядок только если выбранный слот не делает другие дедлайны невыполнимыми.
- Если все задачи одновременно не помещаются, алгоритм продолжает раскладывать наиболее срочные выполнимые задачи, а не останавливается целиком.
- Ручная проверка теперь запрещает резерву пересекать обед; правило буфера одинаково для ручного и авто-режима.
- Импорт гарантирует уникальные ID задач.
- Повреждённые даты Focus-сессий отбрасываются вместо переноса на сегодня.
- Задачи без дедлайна сохраняются как «Без дедлайна» и автоматически планируются в ближайшие 14 дней.
- Дублирующиеся закреплённые/ручные слоты автоматически разделяются: ручной слот сохраняется первым, конфликтующий слот возвращается во входящие.
- Выполненные просроченные задачи показываются как «Выполнено», а не как «Просрочено».
- Focus сохраняет дату начала сессии при переходе через полночь.
- Отмена системного экспорта теперь явно отображается пользователю; при других ошибках остаётся резервный download.
- Удалён неиспользуемый `scheduleSingle()`.
- Для будущих дат убран глобальный счётчик просроченных задач с подписи дня.
- Кнопка планирования теперь явно обозначает глобальную перестройку автоматического плана.
- Схема локальных данных повышена до 9; v8 автоматически мигрирует в v9 без потери пользовательских задач.
- Service Worker обновлён до `flowday-v8.0.0-rc.2`.
- Иконки пересобраны в актуальный набор v9 из пользовательского исходника 1024×1024.

## 8.0.0-rc.1 — Release Candidate
- Перепланирование теперь всегда начинается с сегодняшнего дня, независимо от открытой даты.
- Выполнение и возврат задачи больше не меняют режим ручного/автоматического размещения без причины.
- Просроченный или уже прошедший слот при возврате задачи корректно снимается и передаётся планировщику.
- Focus-таймер переведён на timestamp-модель: сворачивание/блокировка iPhone больше не сбивают отсчёт.
- Во время Focus выбор задачи блокируется; закрытие окна больше не сбрасывает активную сессию.
- Статистика «Твоя неделя» теперь действительно считает завершения и Focus только за выбранную неделю.
- Импорт резервной копии получил строгую нормализацию дат, времени, типов и пустых/сломанных слотов.
- Неполные scheduledDate/scheduledStart автоматически восстанавливаются в безопасное состояние.
- Приоритет получил отдельный вес внутри допустимого диапазона дедлайна; дедлайн остаётся жёстким ограничением.
- Буфер считается частью резервируемой нагрузки и учитывается в проценте занятости.
- В календарь добавлена навигация по предыдущей/следующей неделе.
- Действие «План» явно работает как глобальное «Перестроить автоматический план».
- Исправлено состояние sheets при быстром закрытии/повторном открытии.
- Добавлен реальный online/offline feedback.
- Улучшена accessibility-подпись поиска.
- Обновлён Service Worker до `flowday-v8.0.0-rc.1`.
- Иконки iPhone пересобраны из мастер-файла пользователя 1024×1024.
