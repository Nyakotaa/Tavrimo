# Changelog

## 5.0.0 — Release candidate polish

### Fixed
- исправлена рассинхронизация `id` между HTML и JavaScript из предыдущей версии;
- исправлена запись невалидного ручного слота до прохождения проверки;
- исключены демонстрационные задачи из чистого первого запуска;
- корректнее обрабатываются старые локальные данные v2–v4;
- ручные задачи не двигаются при автопланировании;
- автопланировщик пропускает выходные, если это отключено в настройках;
- исправлены конфликты ручных слотов с учётом буфера;
- исправлена обработка пустых состояний;
- экспорт на iPhone использует системное меню «Поделиться» там, где оно доступно.

### Improved
- уменьшена визуальная плотность главного экрана;
- вторичные функции вынесены в отдельные окна;
- унифицированы цвета и состояния светлой/тёмной темы;
- добавлен экран установки на iPhone;
- добавлен режим управляемого обновления PWA;
- обновлён Service Worker и полностью пересобран app shell;
- добавлена более аккуратная работа с `prefers-reduced-motion`.

### Release infrastructure
- добавлена README для GitHub;
- добавлен гайд публикации через GitHub Pages;
- добавлен гайд обновлений;
- добавлен гайд иконки;
- добавлен release checklist;
- добавлена проверка синтаксиса через GitHub Actions.
