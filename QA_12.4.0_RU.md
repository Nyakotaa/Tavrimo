# Tavrimo 12.4.0 — отчёт проверки

## Цели проверки

- Миграция старых событий РЭУ в локальный календарь с прежними ID.
- Сохранение `linkedUniversityEventId`, задач, истории фокуса, имени и локального аватара.
- Преобразование старых feed-календарей в локальные снимки и очистка URL.
- Единая временная шкала Today/Week.
- Ручной импорт `.ics` с экрана Today.
- Отсутствие фоновой синхронизации при запуске, online, visibilitychange и pageshow.
- Работа профиля, статистики, состояния плана и JSON backup.
- Согласованность версий, Service Worker и HTML IDs.

## Автоматический прогон

Команды для CI:

```bash
node --check app.js
node tools/run_regression.mjs
```

Набор 12.4.0 проверяет ручное планирование, миграцию, ID и ссылки задач, идемпотентность, сохранение локальных feed-снимков, ICS recurrence/timezones/all-day/multi-day, профиль, backup, onboarding, сетевые ограничения и разметку.

## Результаты

Этот файл создаётся вместе с релизной веткой. Итоговые числа должны быть заполнены после завершения GitHub Actions для коммита 12.4.0; до этого статус тестов считается непроверенным.

## Ручная проверка

- Открыть Today; приветствие и дата отображаются корректно.
- Импортировать один и несколько `.ics`-файлов.
- Проверить события Today и Week, повторный импорт того же файла, занятость и конфликты.
- Проверить имя и фото в Profile; перезапустить PWA и убедиться, что они сохранились.
- Экспортировать JSON, очистить тестовую копию приложения и импортировать JSON обратно.
- Открыть ранее установленную копию офлайн и проверить сохранённые данные.

## Ограничения среды

Автоматический статический и unit-тест не заменяет ручной браузерный прогон на реальных iPhone и Android. Отдельно необходимо проверить установку/обновление PWA и поведение системного выбора файлов на обоих типах устройств.
