# Tavrimo 12.4.0 — отчёт проверки

## Автоматическая проверка

Итоговый GitHub Actions прогон для предыдущей сборки: **9/9 PASS**. После обнаружения ошибки переключения экранов добавлены отдельные навигационный smoke test и проверка корректного использования DOM-коллекций. Новые проверки должны войти в повторный прогон перед завершением исправления.

- `node --check app.js`
- `node tools/run_regression.mjs`

## Критическая UI-регрессия, обнаруженная после предыдущего CI

При переключении вкладок `renderAll()` вызывал `renderChrome()`, в которой список вкладок выбирался через одиночный helper `$()` (querySelector) с последующим вызовом `.forEach()`. Это прерывало рендеринг до обновления активного экрана. Исправление: использовать `$$()` (querySelectorAll) для коллекции навигационных кнопок.

Дополнительная проверка теперь проходит по всем одноэлементным DOM-селекторам и запрещает применять к результату `$()` коллекционные методы `forEach/map/filter/find/some/every/reduce/length`. Навигационный smoke test проверяет заголовок, активную вкладку и активный экран для Today, Week, Tasks, More и Profile.

## Что проверяется в regression suite

1. Ручное планирование.
2. Миграция прежних REA events, сохранение оригинальных ID, linkedUniversityEventId, старых feed snapshots и идемпотентность.
3. Импорт ICS: повторения, TZID, all-day и multi-day; повторный импорт без дубликатов.
4. Локальный профиль и аватар.
5. Запрет фоновых сетевых запросов и локальная архитектура.
6. Onboarding.
7. Безопасность JSON backup и rollback при ошибке LocalStorage.
8. Навигация всех пяти экранов (active view, active nav item, topbar title).
9. DOM selector integrity, HTML IDs и наличие элементов для обработчиков.
10. Release/UI структура и версия.
11. Согласованность версий ресурсов, манифеста и Service Worker.

Старые проверки автоматической синхронизации и 12.3.0 остаются в `tools/historical`.

## Что не заменяет CI

Физический браузерный прогон на iPhone/Safari и Android/Chrome нужно выполнить отдельно: установка/обновление PWA, системный file picker, офлайн-перезапуск после импорта ICS. До этого не заявлять о полном ручном QA на реальных устройствах.
