# Tavrimo 12.4.0 — QA и исправление навигации

## Обнаруженная регрессия

После предыдущего релизного PR выявлена критическая ошибка переключения экранов: в `renderChrome()` для коллекции кнопок навигации использовался одиночный DOM-helper `$()` (querySelector), а затем вызывался `.forEach()`. Это прерывало `renderAll()` и не позволяло переключить экран.

Исправление:
- коллекция навигационных кнопок выбирается через `$$()` (querySelectorAll);
- Profile сохраняет подсветку пункта More, сам профиль получает активный экран;
- все пять экранов проверяются навигационным smoke test.

## Новые регрессионные проверки

- `test_navigation_smoke_12_4_0.mjs`: Today, Week, Tasks, More, Profile — заголовок, активная вкладка, активный экран.
- `test_dom_selector_integrity_12_4_0.mjs`: все статические ID-селекторы существуют; одиночный `$()` не используется как коллекция.
- Остальные миграционные, ICS, профильные, local-only, backup и release проверки сохранены.

## Команды

```bash
node --check app.js
node tools/run_regression.mjs
```
