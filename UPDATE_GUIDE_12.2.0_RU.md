# Обновление Tavrimo до 12.2.0

1. Сделайте резервную копию данных через «Ещё → Настройки → Данные → Экспортировать».
2. Обновите файлы репозитория Tavrimo исходниками этой версии, сохранив отдельные пользовательские файлы, если они добавлялись вручную.
3. Дождитесь публикации GitHub Pages/Render.
4. Откройте Tavrimo онлайн один раз. Если приложение было установлено как PWA, полностью закройте его и откройте снова после обновления Service Worker.
5. Проверьте текущие задачи и расписание. Схема данных остаётся v17, поэтому обычное обновление не должно очищать LocalStorage.
6. При необходимости импортируйте созданный ранее JSON backup.

В 12.2.0 визуальная тема стала единой тёмной. Старые настройки `light` / `system` игнорируются для отображения, но существующая запись настроек и остальные пользовательские данные сохраняются.
