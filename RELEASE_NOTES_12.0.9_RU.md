# Tavrimo 12.0.9 — исправление синхронизации РЭУ

## Что исправлено

- Устранена причина ошибки `502`: если адрес с параметром `?q=` не открывал расписание, сервис мог искать поле группы на неподходящей странице.
- Поиск теперь сначала использует основную страницу `https://rasp.rea.ru/` и её обычное поле поиска.
- Если поле не найдено, сервис повторно открывает главную страницу расписания и расширенно ищет поле, не путая его с полями входа.
- Переход по `?q=` остаётся резервным способом.
- Сохранена логика импорта календаря «За всё время» из версии 12.0.8.

## Обновление

1. Распакуйте архив и обновите файлы проекта в своём GitHub-репозитории.
2. Убедитесь, что сервис `tavrimo-rea-sync` на Render собирается из обновлённого репозитория, затем выполните Manual Deploy → Deploy latest commit (если автоматический деплой не запустился).
3. Дождитесь успешного деплоя и в Tavrimo нажмите «Повторить» у расписания.

Если появится новая ошибка, откройте Logs сервиса Render и скопируйте строки с префиксами `[REA_SEARCH_INPUT_MISSING]`, `[REA_SEARCH_INPUT_RETRY]` или `[REA_SYNC_502]`.

Примечание: локальные проверки кода не заменяют проверку на вашем экземпляре Render. Поэтому после деплоя важно повторить синхронизацию.
