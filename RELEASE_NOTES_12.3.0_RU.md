# Tavrimo 12.3.0 — Календари и персональное приветствие

## Новое

- Раздел «Мои календари»: несколько отдельных внешних источников рядом с расписанием РЭУ.
- Импорт одного или нескольких `.ics`-файлов.
- Read-only подключения Google Calendar, Outlook и iCloud по iCalendar URL.
- Ручное обновление, включение/выключение и удаление каждого источника.
- Последний успешный снимок доступен офлайн.
- Внешние занятия учитываются в расписании, загрузке дня и проверке пересечения ручных задач.
- Настройка имени пользователя; экран «Сегодня» показывает «Доброе утро/день/вечер/ночь, Имя!» по локальному времени устройства. Без имени приветствие остаётся нейтральным.

## Совместимость

Схема локальных данных остаётся v17. Университетское расписание РЭУ, задачи, ручные слоты и существующие JSON-backup сохраняют прежнее поведение. Внешние календари и display name добавлены как необязательные поля.

## Важно

Ссылки Google/Outlook/iCloud подключаются как read-only iCalendar feeds; это не OAuth-вход и не двустороннее редактирование. Для работы URL-подписок необходимо развернуть обновлённый Sync Gateway из папки `sync-service`. Одного обновления статических файлов GitHub Pages недостаточно.
