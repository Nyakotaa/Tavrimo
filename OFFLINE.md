# Flowday — офлайн режим

Flowday уже сделан как offline-first PWA.

## Что это означает

После первого открытия по HTTPS и установки через Safari → «Поделиться» → «На экран "Домой"» приложение кэширует весь интерфейс и может работать без интернета.

Задачи, расписание и настройки хранятся локально в памяти браузера (localStorage) на самом iPhone. Сеть для обычной работы планировщика не требуется.

## Важно

1. Первый запуск и установка требуют интернет, потому что Safari должен получить HTML/CSS/JS и установить Service Worker.
2. Не открывайте `index.html` напрямую из Telegram/Файлов: Service Worker не работает для обычного `file://`.
3. Сначала разместите папку сайта на любом HTTPS-хостинге (например, GitHub Pages), один раз откройте в Safari и установите на экран «Домой».
4. После этого Flowday загружает интерфейс из кэша даже при полном отсутствии интернета.
5. Если удалить приложение с экрана «Домой» или очистить данные Safari, локальные задачи могут быть удалены.

## Быстрая проверка офлайна

После установки откройте Flowday онлайн, добавьте тестовую задачу, затем включите авиарежим и снова откройте Flowday. Задача и расписание должны остаться доступны.
