# Иконка Flowday

## Исходник
Используйте PNG `1024×1024` как мастер-файл.

В релизной папке он хранится как:

`assets/icons/source-icon-1024.png`

## Что использует iPhone
Для добавления Flowday на экран «Домой» Safari получает отдельную иконку:

`assets/icons/apple-touch-icon-v6.png` — 180×180

В проекте также есть:
- `icon-192.png` — 192×192
- `icon-512.png` — 512×512
- `icon-180.png` — 180×180
- `favicon-32.png` — 32×32

### Почему новая иконка могла не появиться
Уже установленная веб-иконка может оставаться старой из кэша/записи на экране «Домой». В v6 изменился URL `apple-touch-icon`, поэтому новая публикация получает отдельный адрес. Для гарантированной замены старой иконки удалите старый Flowday с экрана «Домой» и добавьте сайт заново из Safari.

## Замена иконки
1. Замените `source-icon-1024.png` своей картинкой 1024×1024.
2. Запустите `python tools/build_icons.py`.
3. Загрузите полученные PNG в `assets/icons/`.
4. Если меняется URL иконки, обновите ссылку `apple-touch-icon` в `index.html`.
