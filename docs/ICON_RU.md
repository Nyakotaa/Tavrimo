# Иконка Flowday

## Для iPhone PWA

Основной файл iOS Web Clip:

- `assets/icons/apple-touch-icon-v5.png`
- размер: **180 × 180 px**
- формат: PNG

В manifest также используются:

- `assets/icons/icon-192.png` — 192 × 192 px
- `assets/icons/icon-512.png` — 512 × 512 px

Safari/WebKit использует `apple-touch-icon`, если он объявлен в HTML, и эта ссылка имеет приоритет над manifest-иконками. citeturn549584search3turn946672search8

## Самый удобный исходник

Храни мастер-иконку в:

`assets/icons/source-icon-1024.png`

Рекомендуемый размер мастера:

**1024 × 1024 px**

Из него можно генерировать web-иконки нужных размеров.

Для нативного iOS-приложения/App Store 1024 × 1024 px также является базовым размером единого исходника для App Icon в asset catalog. citeturn549584search0

## Почему моя новая иконка не появилась

В предыдущей версии ссылка была на конкретный файл `icon-180.png`. Если ты заменил содержимое этого же файла, iPhone мог продолжить использовать уже сохранённую иконку Web Clip.

В этом релизе имя файла специально версионировано:

`apple-touch-icon-v5.png`

Это уменьшает шанс, что старый ресурс останется привязан к той же URL.

Для уже установленной старой иконки самый надёжный способ — удалить старый Flowday с экрана «Домой» и добавить сайт заново после обновления.

## Как заменить иконку

### Вариант без терминала

Положи свою иконку 1024×1024 в `assets/icons/source-icon-1024.png` и попроси меня подготовить пакет с готовыми web-иконками. Это самый простой путь.

### Вариант с локальным скриптом

Установи Python и выполни:

```bash
python3 tools/build_icons.py
```

После этого залей изменённые PNG на GitHub Pages и переустанови Web Clip на iPhone.
