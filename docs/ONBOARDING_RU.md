# Обучение Tavrimo

При первом запуске Tavrimo автоматически показывает короткое интерактивное обучение. Оно последовательно подсвечивает главные элементы приложения:

1. **📈 День** — загрузка выбранной даты и общий статус.
2. **📅 Дата** — переход к другому дню.
3. **➕ Добавление** — единственная кнопка создания задачи; время назначается вручную или задача остаётся без времени.
4. **🎓 Неделя и РЭУ** — недельный план, подключение группы и расписание пар.
5. **✅ Задачи** — поиск и фильтры библиотеки.
6. **🧩 Ещё** — Фокус, Статистика, Состояние плана, Моя группа и Настройки.
7. **🎓 Моя группа РЭУ** — номер группы, официальный календарный экспорт `.ics`, пары с преподавателем/аудиторией и связь задач с конкретной парой.
8. **⚙️ Настройки** — рабочее время, обед, резерв, выходные, тема и резервные копии.

Обучение можно пропустить в любой момент. Повторно открыть его можно в **Настройки → Показать обучение**.

Состояние прохождения хранится локально на устройстве. Оно не отправляется на сервер.
