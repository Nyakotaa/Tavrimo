# Обучение Tavrimo

При первом запуске Tavrimo автоматически показывает интерактивное обучение. Оно подсвечивает главный экран, выбор даты, единственную кнопку добавления задачи, недельный обзор, библиотеку задач, раздел «Ещё» и настройки.

Обучение можно пропустить в любой момент. Повторно открыть его можно в **Настройки → Показать обучение**.

Состояние прохождения хранится локально на устройстве. Оно не отправляется на сервер.
