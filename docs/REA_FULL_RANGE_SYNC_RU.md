# Полная синхронизация расписания РЭУ

Официальный `rasp.rea.ru` содержит переключатель недель по всему доступному учебному циклу. Tavrimo 12.1.0 использует этот интерфейс как источник: после выбора группы сервер последовательно открывает доступные номера недель и разбирает фактически отображённые занятия. Это позволяет не ограничиваться текущей неделей.

Ручное обновление = полный проход всех опубликованных недель.
Фоновое обновление = текущая неделя; периодически выполняется полный проход.

Источник: https://rasp.rea.ru/
