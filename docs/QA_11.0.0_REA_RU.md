## Проверенные сценарии

1. Импорт стандартного timed ICS с `TZID=Europe/Moscow`.
2. Чтение преподавателя из `DESCRIPTION`.
3. Чтение аудитории из `LOCATION`.
4. Чтение типа занятия из `SUMMARY/CATEGORIES`.
5. UTC-значение `Z` приводится к московскому времени.
6. All-day `VALUE=DATE` событие не превращается в фиктивную пару.
7. Дубли событий удаляются.
8. Стабильный ID сохраняется при изменении порядка событий и повторном импорте.
9. `universityEventsForDate` использует переданный массив событий.
10. Связь задачи с парой сохраняется при нормализации и очищается, если событие исчезло.
11. Пара блокирует конфликтующий ручной слот задачи.
12. Пары входят в расчёт загрузки дня.
13. Общая повестка объединяет пары и ручные задачи.
14. Изменение группы не смешивает старое и новое расписание.

## Ограничение тестовой среды

Проверка конкретного реального `.ics`, экспортированного для вашей группы РЭУ, должна выполняться отдельно. Базовые тесты используют валидный синтетический ICS, построенный по поддерживаемой модели календаря.

Полноценный физический тест на iPhone из среды разработки невозможен; перед публикацией нужно проверить установку PWA, обновление Service Worker, новую иконку и работу без сети на реальном устройстве.
