# 12.0.4 — Refresh + REA fallback

Исправления:
1. Ручное обновление расписания теперь не блокируется текущей фоновой синхронизацией.
2. GitHub Pages использует ваш Render gateway по умолчанию.
3. Parser fallback восстанавливает занятия из разделённого текстового layout текущего `rasp.rea.ru`.
4. В логах Render появляется `[REA_SYNC_FALLBACK]`, если календарь восстановлен из видимого расписания.
