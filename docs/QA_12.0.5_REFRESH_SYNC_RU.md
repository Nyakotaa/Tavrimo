# QA — Tavrimo 12.0.5

## Что исправлено

1. Кнопка `Обновить` могла молча блокироваться. Теперь она всегда кликабельна и запускает принудительную синхронизацию.
2. Старый JS после deploy мог оставаться в PWA cache. Добавлен cache-busting и network-first для основных статических ресурсов.
3. `navigator.onLine` больше не отменяет ручную попытку обновления.
4. Sync Gateway ранее блокировал Service Worker `rasp.rea.ru`, из-за чего официальный портал мог показывать offline/stale состояние и возвращать пустой поиск. Теперь service worker портала разрешён.
5. Поиск группы выполняет явный submit и выбирает результат только после проверки, что открыта реальная страница расписания.
