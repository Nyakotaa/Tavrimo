# Flowday v5.0.0

Релизная полировка Flowday перед публичным использованием.

## Что изменилось

- чистый первый запуск без демо-задач;
- переработанный iOS-first интерфейс;
- единая система цветов и тем;
- исправленная валидация ручного расписания;
- более устойчивое автопланирование;
- аккуратное перепланирование после изменения длительности или дедлайна;
- поддержка рабочих дней и опциональных выходных;
- обновлённый offline-first app shell;
- уведомление о новой версии внутри приложения;
- экспорт/импорт резервной копии;
- отдельные гайды по GitHub Pages, обновлениям и иконке.

## Установка

Открой GitHub Pages URL в Safari на iPhone → `Поделиться` → `На экран «Домой»`.

После первого запуска Flowday продолжает работать без интернета.

## Важно

Личные задачи хранятся локально на устройстве и не попадают в GitHub.
