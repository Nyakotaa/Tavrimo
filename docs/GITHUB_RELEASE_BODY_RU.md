# Flowday v7.0.0

Обновление, в котором планировщик начинает использовать параметры задачи по назначению: дедлайн, длительность и приоритет реально меняют результат планирования.

## Главное

- Дедлайн теперь ограничивает фактический слот, включая необязательное точное время.
- Длительность задаёт реальный размер блока и влияет на процент занятости.
- Приоритет влияет на порядок задач с близкими дедлайнами.
- Автоматически выбранное время проходит через реальные рабочие окна, перерыв и занятые слоты.
- Ручное время проверяется на прошлое, рабочие часы, обед, дедлайн и пересечения.
- Если изменить длительность, приоритет или дедлайн у автоматической задачи, Flowday пересобирает автоматический план.
- Перевод ручной задачи обратно в авто возвращает её планировщику.
- На расписании явно показываются начало и конец задачи.
- Обновлена пользовательская иконка iPhone/PWA.
- Service Worker обновлён до `flowday-v7.0.0`.

## Важно

Дедлайн сам по себе не увеличивает «занятость»: он задаёт крайний момент, до которого задача должна попасть в расписание. Процент занятости меняется после того, как задача получает реальный слот.

## Установка

Открой GitHub Pages URL в Safari на iPhone → `Поделиться` → `На экран «Домой»`.

## Обновление

После публикации новой версии открой Flowday с интернетом. Если появится `Доступна новая версия`, нажми `Обновить`.
