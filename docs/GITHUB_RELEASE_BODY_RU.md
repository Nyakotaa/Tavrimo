## Flowday 8.0.0 RC1

Первая Release Candidate после полного QA-аудита 7.0.0.

### Главное
- Исправлено глобальное перепланирование из будущей даты.
- Исправлено сохранение ручного режима при выполнении/возврате задачи.
- Focus теперь считает время по timestamp и переживает сворачивание PWA.
- Статистика недели считает только выбранную неделю.
- Импорт резервных копий стал безопаснее.
- Приоритет, длительность и буфер имеют реальное влияние на план и загрузку.
- Добавлена навигация по неделям.
- Обновлены иконки из пользовательского мастер-файла.

### Для установки
Загрузите содержимое `personal-planner` в GitHub Pages и откройте опубликованный HTTPS-адрес в Safari.

### Важно
RC1 требует финальной проверки на физическом iPhone перед production-использованием.
