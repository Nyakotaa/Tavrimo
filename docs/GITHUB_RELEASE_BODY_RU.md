# Flowday 9.0.0

## Что нового

- «Дальше» на главном экране показывает текущую или следующую задачу.
- «Состояние плана» помогает быстро увидеть просрочки, задачи без времени, ближайшие дедлайны и перегруженные дни.
- Новые фильтры задач: с дедлайном, без времени и просроченные.
- В недельном обзоре появились компактные индикаторы загрузки по дням.
- В карточке редактирования задачи добавлены «Найти время» и «Без времени».
- Явные статусы задач: авто, вручную, без времени, нужен перенос, готово.
- Улучшен iOS-first интерфейс без добавления лишних основных кнопок.
- Обновлена offline-кэш схема и локальная схема данных.
