# Flowday 8.0.0 RC2

Вторая release candidate версия Flowday после углублённого QA 8.0.0 RC1.

## Исправлено
- deadline-safe автопланирование: приоритет не ломает более ранние дедлайны;
- ручной буфер не может пересечь обед;
- импорт гарантирует уникальные ID;
- битые даты Focus-сессий не переносятся на сегодня;
- задачи без дедлайна сохраняются без искусственной даты и планируются в ограниченном горизонте;
- конфликтующие закреплённые слоты ремонтируются безопасно;
- выполненные задачи больше не показываются как просроченные;
- Focus сохраняет дату начала сессии;
- экспорт даёт обратную связь при отмене.

## Проверки
`node tools/test_scheduler.mjs` должен завершиться сообщением `Scheduler regression tests passed.`

## Ручная проверка перед финалом
- обновление RC1 → RC2 на iPhone;
- Home Screen icon;
- офлайн-запуск;
- Focus при блокировке экрана;
- импорт/экспорт backup;
- ручной слот рядом с обедом;
- изменение дедлайна/длительности/приоритета.
