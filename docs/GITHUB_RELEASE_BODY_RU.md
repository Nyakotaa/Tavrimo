# Tavrimo 11.0.0 — Расписание РЭУ

Tavrimo теперь объединяет расписание группы РЭУ и ручной планировщик задач.

### Основное

- импорт официального расписания РЭУ из `.ics`;
- преподаватели, аудитории, тип занятия и время;
- пары учитываются в загрузке дня и блокируют конфликтующие задачи;
- задачи можно привязать к конкретной паре;
- календарь недели и единая повестка дня;
- ручная расстановка задач;
- Focus, статистика, резервные копии и офлайн-режим;
- безопасный повторный импорт расписания.

### Источник

Официальный портал: https://rasp.rea.ru/

Tavrimo не является официальным приложением РЭУ.
