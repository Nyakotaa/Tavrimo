# Flowday v6.0.0

Релизная полировка Flowday перед публичным использованием.

## Главное

- полностью пустой первый запуск без заготовленных задач;
- одна единая кнопка `+` для создания задач;
- убраны лишние кнопки и встроенные справочные экраны;
- рабочая кнопка выбора даты на главном экране;
- управление автопланом вынесено в отдельное компактное окно;
- обновлённая визуальная система и контрастная тёмная тема;
- исправлена логика ручных слотов и конфликтов;
- автоматическое перепланирование после существенных изменений настроек;
- сохранён offline-first режим;
- обновлён Service Worker и механизм уведомления о новой версии;
- добавлена новая пользовательская иконка для iPhone/PWA;
- обновлены README и инструкции проекта.

## Установка

Открой GitHub Pages URL в Safari на iPhone → `Поделиться` → `На экран «Домой»`.

После первого запуска Flowday продолжает работать без интернета.

## Данные

Личные задачи, расписание и настройки хранятся локально на устройстве и не передаются в GitHub.

## Иконка

Мастер-файл: `assets/icons/source-icon-1024.png` — 1024×1024 PNG.

## Обновление

После публикации новой версии открой Flowday с интернетом. Если появится баннер `Доступна новая версия`, нажми `Обновить`.
