# Чек-лист релиза Flowday

## Перед публикацией

- [ ] В репозитории нет реальных личных задач пользователей.
- [ ] README содержит описание проекта.
- [ ] `index.html` находится в корне публикации.
- [ ] GitHub Pages настроен на `main / (root)`.
- [ ] Сайт открывается по HTTPS.
- [ ] Service Worker успешно регистрируется.
- [ ] Первый запуск пустой.
- [ ] Создание задачи работает.
- [ ] Ручное время валидируется.
- [ ] Автопланирование не создаёт пересечений.
- [ ] Ручные блоки не двигаются.
- [ ] Завершение и редактирование работают.
- [ ] Экспорт/импорт работают.
- [ ] Светлая и тёмная темы читаемы.
- [ ] Установка на iPhone работает через Safari.
- [ ] После установки приложение работает в авиарежиме.
- [ ] Обновление Service Worker показывает новый релиз.
- [ ] Иконка соответствует текущей версии.

## После публикации

- [ ] Создан GitHub Release.
- [ ] В Release Notes указана версия.
- [ ] Ссылка на PWA проверена с другого устройства.
- [ ] В Telegram опубликована ссылка на сайт.
