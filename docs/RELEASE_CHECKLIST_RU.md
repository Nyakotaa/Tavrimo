# Чек-лист релиза Flowday

## Перед публикацией

- [ ] Первый запуск пустой, без демо-задач.
- [ ] `index.html` находится в корне публикации.
- [ ] GitHub Pages настроен на `main / (root)`.
- [ ] Сайт открывается по HTTPS.
- [ ] Service Worker регистрируется.
- [ ] На главной нет неактивной кнопки «домой».
- [ ] Центральная `+` создаёт задачу.
- [ ] Нет дополнительных кнопок создания задачи на других экранах.
- [ ] Кнопка даты на главном экране открывает выбор даты.
- [ ] Навигация Сегодня / Неделя / Задачи / Ещё работает.
- [ ] Кнопка «Сегодня» на экране недели возвращает текущую дату.
- [ ] Поиск и фильтр задач работают.
- [ ] Редактирование, завершение и удаление работают.
- [ ] Ручное время валидируется и не допускает конфликтов.
- [ ] Автопланирование не создаёт пересечений.
- [ ] Ручные блоки не двигаются при автопланировании.
- [ ] Изменение настроек корректно пересобирает автоматический план.
- [ ] Фокус, статистика и настройки открываются.
- [ ] Экспорт и импорт резервной копии работают.
- [ ] Светлая, тёмная и системная темы читаемы.
- [ ] После установки на iPhone приложение работает в авиарежиме.
- [ ] Service Worker показывает новый релиз.
- [ ] Новая пользовательская иконка отображается после повторного добавления на экран «Домой».
