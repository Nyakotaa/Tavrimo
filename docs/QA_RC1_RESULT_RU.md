# QA result — Flowday 8.0.0 Release Candidate 1

## Итог

RC1 закрывает дефекты, найденные в аудите Flowday 7.0.0, и подготовлен к повторному регрессионному тестированию.

## Автоматические проверки

- JavaScript syntax check — PASS
- Service Worker syntax check — PASS
- Scheduler unit/regression tests — PASS
- HTML id/reference consistency — PASS
- Manifest/local asset checks — PASS
- App icon dimensions/hash — PASS

## Исправленные области

- глобальное автопланирование всегда стартует с сегодняшнего дня и не меняет ручные блоки;
- выполнение/отмена выполнения сохраняет режим ручного расписания, пока слот валиден;
- Focus использует абсолютное время окончания и пересчитывается после background/visibility changes;
- выбранную задачу Focus нельзя менять во время активной сессии;
- статистика считается по выбранной неделе;
- импорт нормализует даты, время, параметры настроек и задачи;
- приоритет влияет на очередность внутри допустимого дедлайном окна;
- резерв учитывается в загрузке дня;
- неполные/осиротевшие слоты очищаются;
- календарь поддерживает предыдущую/следующую неделю;
- настройки и перепланирование синхронизированы;
- connection state показывает понятный toast;
- поиск получил accessible label;
- версия и Service Worker обновлены до 8.0.0-rc.1.

## Перед финальным 8.0.0

Нужен финальный ручной smoke-тест на физическом iPhone после публикации на GitHub Pages: установка/обновление PWA, offline launch, создание и ручное расписание, автоплан, Focus после сворачивания, импорт/экспорт и замена иконки.
