# Обновление Tavrimo

Tavrimo — PWA. Когда доступна новая версия, браузер загружает обновлённую оболочку приложения через Service Worker.

1. Подключитесь к интернету и откройте Tavrimo.
2. Если в приложении появился баннер «Доступна новая версия», нажмите «Обновить».
3. Если баннера нет, закройте приложение и откройте его снова позже — браузер проверит обновление оболочки.
4. Не удаляйте Tavrimo и не очищайте данные сайта для обычного обновления.

Задачи, календарные данные, настройки и профиль хранятся отдельно от файлов интерфейса. Тем не менее перед крупными изменениями рекомендуется создать резервную копию через «Ещё» → «Настройки» → «Экспортировать».

Импорт JSON заменяет текущий набор данных. Перед восстановлением убедитесь, что сохранена актуальная копия.
