# Обновление Flowday

1. В репозитории замените содержимое файлами новой версии.
2. Нажмите **Commit changes**.
3. Подождите, пока GitHub Pages обновит сайт.
4. Откройте Flowday на iPhone с интернетом.
5. Если появится **«Доступна новая версия»**, нажмите **«Обновить»**.
6. Полностью закройте Flowday и откройте снова.

### Если осталась старая иконка
Safari может хранить иконку отдельно от кэша сайта. Удалите старую иконку Flowday с экрана «Домой», затем снова откройте сайт в Safari и выберите `Поделиться → На экран «Домой»`.

### Данные
Обновление файлов сайта не удаляет локальные задачи: они находятся в `localStorage` на устройстве. Перед крупными обновлениями рекомендуется сделать экспорт резервной копии.
