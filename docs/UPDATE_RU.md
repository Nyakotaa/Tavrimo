# Обновление Tavrimo 8 → 9

1. Скачайте ZIP релиза.
2. Загрузите содержимое папки `personal-planner` в корень существующего GitHub Pages репозитория.
3. Не меняйте путь `index.html` в корне публикации.
4. Откройте Tavrimo на iPhone с интернетом.
5. Если появится «Доступна новая версия», нажмите «Обновить».
6. Для гарантированной новой иконки удалите старую иконку Tavrimo с домашнего экрана и добавьте сайт снова через Safari.

Локальные задачи, расписание, настройки и Focus хранятся отдельно от GitHub Pages и не должны удаляться обычным обновлением.
