# Как выпускать обновления Flowday

## Для разработчика

1. Измени файлы в папке проекта.
2. В `app.js` поменяй `APP_VERSION`, например `5.0.0` → `5.1.0`.
3. В `sw.js` поменяй значение `VERSION`, например `flowday-v5.0.0` → `flowday-v5.1.0`.
4. Обнови номер версии в `manifest.webmanifest` и README, если он там указан.
5. Залей новые файлы в тот же GitHub-репозиторий.
6. Сделай Commit changes.

## Для пользователя

После выхода новой версии:

1. подключись к интернету;
2. открой Flowday;
3. если появилось сообщение «Доступна новая версия», нажми `Обновить`;
4. если сообщения нет, закрой Flowday и открой его снова через несколько секунд.

## Важно про локальные данные

Обновление файлов сайта не должно стирать задачи, потому что задачи лежат в `localStorage` конкретного устройства. Не меняй `STORAGE_KEY`, если нет специальной причины.

## Если пользователь всё ещё видит старую версию

1. открой Flowday именно из иконки на экране «Домой`;
2. включи интернет;
3. подожди 5–10 секунд;
4. закрой приложение;
5. запусти снова.

Если после этого версия не меняется, удали приложение с экрана «Домой» и установи его заново. Перед этим сделай экспорт JSON, чтобы сохранить задачи.
