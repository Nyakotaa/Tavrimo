# Как выпускать обновления Flowday

## Для разработчика

1. Измени файлы в папке проекта.
2. В `app.js` увеличь `APP_VERSION`.
3. В `sw.js` измени значение `VERSION` на ту же версию.
4. Если менялась иконка, обнови адрес `apple-touch-icon` в `index.html`.
5. Загрузи новые файлы в тот же GitHub-репозиторий.
6. Сделай `Commit changes`.

Версия 6.0.0 уже использует отдельный cache name `flowday-v6.0.0` и URL иконки `apple-touch-icon-v6.png`.

## Для пользователя

1. Подключись к интернету.
2. Открой Flowday.
3. Дождись появления `Доступна новая версия`.
4. Нажми `Обновить`.
5. После перезагрузки приложение продолжит работать офлайн.

## Важно про локальные данные

Обновление файлов сайта не стирает задачи, потому что они хранятся в `localStorage` конкретного устройства. Не меняй `STORAGE_KEY` без миграции.

Перед крупным обновлением можно сделать `Ещё → Настройки → Экспортировать`.

## Если новая версия не появилась

Открой сайт в Safari с интернетом, подожди несколько секунд и перезапусти Flowday. В крайнем случае удали только иконку с экрана «Домой» и добавь сайт снова. Экспорт JSON позволяет заранее сохранить данные.
