# Tavrimo 12.0.2 — исправление 502

В 12.0.2 Sync Gateway стал устойчивее к динамическому сайту rasp.rea.ru. Исправления включают:

1. выбор точного совпадения группы из подсказки;
2. ожидание состояния расписания вместо фиксированной паузы;
3. поддержку iCalendar как browser download, обычного HTTP-ответа и сетевого ресурса;
4. Render-friendly параметры Chromium для ограниченной памяти;
5. timeout синхронизации 60 секунд;
6. диагностический лог `[REA_SYNC_502]` для Render.

## После заливки на GitHub

Render должен автоматически создать новый deploy. Если нет — в сервисе Render нажмите Manual Deploy → Deploy latest commit.

Проверка: `GET /api/rea/health`, затем повторить выбор группы.
