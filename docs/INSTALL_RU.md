# Установка Tavrimo на iPhone

## 1. Опубликуй сайт

1. Создай на GitHub репозиторий `tavrimo`.
2. Загрузи содержимое папки `personal-planner` в корень репозитория.
3. Открой `Settings → Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Ветка: `main`.
6. Папка: `/(root)`.
7. Нажми `Save`.
8. Дождись ссылки вида `https://USERNAME.github.io/tavrimo/`.

## 2. Установи на iPhone

1. Открой ссылку в **Safari**.
2. Подожди, пока Tavrimo полностью загрузится.
3. Нажми кнопку **Поделиться**.
4. Выбери **На экран «Домой»**.
5. Нажми **Добавить**.
6. Запускай Tavrimo с иконки на экране «Домой».

Не используй `index.html`, открытый как локальный файл из Telegram или приложения «Файлы»: для PWA нужен HTTPS-сайт, чтобы Service Worker мог работать.

## 3. Проверь офлайн

1. Открой Tavrimo один раз с интернетом.
2. Создай тестовую задачу.
3. Полностью закрой Tavrimo.
4. Включи авиарежим.
5. Снова открой Tavrimo с экрана «Домой».

Задача должна остаться на месте.

## Если иконка старая

Удалить старую иконку Tavrimo с экрана «Домой», обновить сайт, снова открыть его в Safari и заново добавить на экран «Домой». В iOS Web Clip использует `apple-touch-icon`, а ссылка на этот файл имеет приоритет над иконками из manifest.
