# Установка Tavrimo на смартфон

Tavrimo — веб-приложение формата PWA. Его можно добавить на главный экран телефона и открывать в отдельном окне, как обычное приложение.

Для первой установки откройте опубликованный HTTPS-адрес Tavrimo и дождитесь полной загрузки страницы при подключённом интернете.

## iPhone

Для установки используйте Safari.

1. Откройте ссылку Tavrimo в Safari.
2. Нажмите «Поделиться».
3. В списке действий выберите «На экран Домой». Если пункта нет, найдите его в списке доступных действий.
4. Если отображается переключатель «Открывать как веб-приложение», включите его.
5. Нажмите «Добавить».
6. Запустите Tavrimo с появившейся иконки на главном экране.

## Android

Для установки используйте Google Chrome.

1. Откройте ссылку Tavrimo в Chrome.
2. Нажмите меню браузера (⋮).
3. Выберите «Установить приложение» или «Установить и создать ярлык». В некоторых версиях браузера может отображаться пункт «Добавить на главный экран».
4. Подтвердите установку.
5. Запустите Tavrimo с иконки в списке приложений или на главном экране.

## После установки

- Первый запуск и установка требуют подключения к интернету.
- После успешной загрузки приложение сохраняет оболочку для повторных запусков; ранее сохранённые задачи и календарные события доступны на этом устройстве.
- Данные Tavrimo хранятся локально и не синхронизируются автоматически между разными устройствами.
- Для переноса данных создайте резервную копию: «Ещё» → «Настройки» → «Экспортировать». Импорт JSON заменяет текущие данные, поэтому перед импортом рекомендуется сохранить отдельную копию.

Tavrimo устанавливается через браузер и не требует отдельного установочного файла.
