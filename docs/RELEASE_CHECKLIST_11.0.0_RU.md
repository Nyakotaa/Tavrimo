# Tavrimo 11.0.0 — release checklist

## Университет

- [x] Официальный портал РЭУ указан как источник расписания
- [x] Импорт `.ics`
- [x] Группа сохраняется отдельно
- [x] Преподаватель и аудитория читаются из доступных ICS-полей
- [x] Тип занятия и время отображаются
- [x] Пары блокируют ручные задачи
- [x] Пары участвуют в загрузке дня
- [x] Пары и задачи объединены в дневной повестке
- [x] Задачи можно связать с парой
- [x] Повторный импорт сохраняет стабильные связи по UID/содержимому

## Надёжность

- [x] Дубликаты событий удаляются
- [x] `VALUE=DATE` не превращается в фиктивную пару
- [x] UTC приводится к московскому времени
- [x] Битые ссылки на события очищаются
- [x] Импорт не смешивает расписания при смене группы
- [x] Офлайн-кеш версионируется

## Перед публикацией

- [ ] Проверить конкретный экспорт `.ics` вашей группы РЭУ
- [ ] Открыть Tavrimo в Safari на физическом iPhone
- [ ] Добавить на экран «Домой»
- [ ] Проверить иконку
- [ ] Проверить пары после обновления страницы
- [ ] Включить авиарежим и открыть приложение
- [ ] Создать задачу в окно между двумя парами
- [ ] Проверить конфликт задачи с парой
