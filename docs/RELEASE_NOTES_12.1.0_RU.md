# Tavrimo 12.1.0 — REA Full Range Sync

## Главное
Ручная кнопка «Обновить» и первоначальная загрузка теперь собирают все опубликованные недели, доступные в переключателе недель официального портала РЭУ — и прошлые, и будущие.

## Автоматическая синхронизация
- каждые 15 минут проверяется текущая неделя;
- полное сканирование выполняется при первом подключении и не чаще одного раза в 6 часов;
- уже сохранённое полное расписание не заменяется результатом частичной проверки;
- если текущая неделя на портале стала пустой, старые занятия именно этой недели удаляются, остальные остаются.

## Ограничение источника
Tavrimo показывает только те недели, которые сам портал `https://rasp.rea.ru/` отдаёт через свой переключатель недель. Если РЭУ ещё не опубликовал занятия на дату, Tavrimo не может их придумать.
