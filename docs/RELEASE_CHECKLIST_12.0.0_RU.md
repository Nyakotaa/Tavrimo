# Tavrimo 12.0.0 — release checklist

## PWA
- [ ] `index.html` открывается по HTTPS.
- [ ] Service Worker устанавливается.
- [ ] Приложение запускается без сети после первого онлайн-запуска.
- [ ] Новая иконка добавляется на экран «Домой» Safari.

## РЭУ
- [ ] Введён корректный номер группы.
- [ ] После сохранения группа отправляется в Sync Gateway без ручного скачивания `.ics`.
- [ ] На `/api/rea/health` возвращается `ok: true`.
- [ ] Первичная синхронизация загружает занятия.
- [ ] В карточках есть дата, время, предмет, тип, преподаватель и аудитория, если они есть в официальном экспорте.
- [ ] Изменение времени/даты/преподавателя/аудитории/типа/предмета отражается после следующей проверки.
- [ ] Связанные задачи не теряют связь при однозначном сопоставлении события.
- [ ] При конфликте новой пары и ручной задачи задача возвращается во входящие.
- [ ] Пустой или неполный ответ не стирает последнее известное расписание автоматически.

## Sync Gateway
- [ ] Gateway развёрнут с HTTPS.
- [ ] Playwright/Chromium доступен (Docker-образ или `npx playwright install chromium`).
- [ ] CORS разрешает origin PWA.
- [ ] `If-None-Match` / `ETag` работает.
- [ ] API-ответы не кэшируются браузером.
- [ ] Лимит запросов не мешает нормальной работе нескольких пользователей.

## Основные функции
- [ ] Ручное создание задачи.
- [ ] Длительность, приоритет и дедлайн влияют на валидацию.
- [ ] Пары блокируют время ручных задач.
- [ ] Выполнение задачи не ломает ручной слот.
- [ ] Focus корректен после сворачивания/возврата.
- [ ] Импорт/экспорт JSON работает.
- [ ] Статистика и фильтры не ломаются после синхронизации.
