# QA 12.0.7 — REA Sync Resolution

## Цель
Устранить сценарий, при котором Render успешно запускает Chromium и открывает `rasp.rea.ru`, но Tavrimo получает `502` из-за того, что портал не был переведён с результатов поиска на выбранную группу или экспорт `.ics` не был пойман.

## Исправления
- прямой переход на `https://rasp.rea.ru/?q=<группа>` как первый путь;
- варианты нормализации тире и пробелов;
- выбор через `select`, `role=option`, ссылки, кнопки, текстовые элементы и совпадение query в `href`;
- клавиатурный fallback для autocomplete;
- не нажимать внутреннюю кнопку «Обновить» РЭУ автоматически после выбора;
- если расписание уже видно на странице, сначала разбирать его и только потом пробовать `.ics`;
- результат парсинга рендеренного текста превращается в детерминированный iCalendar;
- предыдущий кэш сохраняется при неуспешной проверке.
