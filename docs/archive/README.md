# Архив технической документации

Здесь сохранены материалы прежних внутренних итераций Tavrimo.

Эти документы полезны для восстановления технического контекста и истории проекта, но **не описывают текущий пользовательский состав функций**. Актуальная документация находится в корневом README и в текущих инструкциях из папки `docs`.

- `legacy-releases/` — релизные заметки, QA-отчёты и инструкции прежних сборок.
- `legacy-calendar-integration/` — описание прежней интеграции с расписанием РЭУ, Sync Gateway и статическими снимками групп.

Архив не меняет и не переписывает историю Git. Он только отделяет старые материалы от действующего описания продукта.
