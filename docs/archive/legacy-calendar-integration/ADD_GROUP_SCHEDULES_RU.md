# Как добавить расписание новой группы в Tavrimo

Tavrimo поддерживает несколько локальных снимков ICS через `data/schedules/manifest.json`. Для каждой новой группы нужен отдельный проверенный `.ics`.

## Порядок

1. На Vuzio выберите конкретную учебную группу и создайте отдельную ссылку календаря.
2. Скачайте именно `.ics` этой группы. Не присылайте один и тот же URL повторно под разными названиями.
3. Проверьте `X-WR-CALNAME` внутри файла: он должен соответствовать коду группы.
4. Поместите файл в `data/schedules/` с уникальным именем латиницей, например `rea-15-14d-new-group.ics`.
5. Добавьте запись в `manifest.json`:

```json
{
  "groupCode": "15.14Д-НОВАЯ/26б",
  "file": "data/schedules/rea-15-14d-new-group.ics",
  "revision": "vuzio-YYYYMMDD-HHMMSSz-N-events",
  "capturedAt": "YYYY-MM-DDTHH:MM:SSZ",
  "source": "Vuzio · календарный снимок",
  "calendarNameIncludes": "Расписание 15.14Д-НОВАЯ/26б",
  "minimumEvents": 1,
  "coverageStart": "YYYY-MM-DD",
  "coverageEnd": "YYYY-MM-DD"
}
```

6. Добавьте новую версионированную ссылку на ICS в массив `SHELL` в `sw.js`, если файл должен быть доступен офлайн сразу после установки/обновления.
7. Запустите `node tools/run_regression.mjs` и отдельную проверку нового ICS по шаблону `tools/test_vuzio_mm05_snapshot.mjs`.

## Важные правила

- Один `groupCode` — один свой календарный файл. Нельзя указывать один ICS под несколькими группами.
- Проверяйте `X-WR-CALNAME`, количество событий и фактический диапазон дат до добавления.
- Не публикуйте секретную URL-ленту с токеном в репозитории. Публикуйте только скачанное содержимое `.ics`.
- Не называйте снимок live-синхронизацией: статический файл обновится только после новой выгрузки и изменения `revision`.
- Не удаляйте существующие записи и встроенный fallback для группы `15.14Д-ГГ04/266`.
