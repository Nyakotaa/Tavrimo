# QA Tavrimo 12.2.0 — Dark UI refresh

## Базовая версия и объём

- Основа: Tavrimo 12.1.6 из handoff-архива от 23 ноября 2026 года.
- Изменения интерфейса: новый `spotify-dark.css`, обновлённая центральная шапка Tavrimo, единая тёмная палитра и адаптивная навигация.
- Модель пользовательских данных остаётся schema version 17 (`tavrimo-planner-v17`).

## Дизайн

- Фон: `#121212`; поверхности: `#181818`, `#1F1F1F`; карточки: `#252525`, `#272727`.
- Акцент: `#1ED760`, только для активных состояний и главных действий.
- Логотип: оригинальная чашка Tavrimo; шрифт: Inter/system sans-serif с кириллическими fallback.
- Mobile: bottom navigation. Desktop (896 px+): sidebar navigation.
- Переключение на светлую тему отключено, старые сохранённые данные не сбрасываются.

## Регрессия — фактически выполнено

Команда: `node tools/run_regression.mjs`.

Результат: **16/16 тестов пройдены**.

Дополнительно выполнены `node --check` для `app.js`, `config.js`, `sw.js`; разбор `RELEASE_MANIFEST.json` и `manifest.webmanifest`; статическая проверка уникальности HTML ID; разбор CSS через `tinycss2` — 0 ошибок, включая правила внутри media queries.

Регрессионный набор покрывает ручное планирование, расписание, оба ICS-снимка (46 и 48 событий), импорт ICS и JSON backup, onboarding, Sync Gateway guardrails и release consistency. Схема данных v17 не менялась.

## Не проверено в этой среде

- Реальный браузерный визуальный прогон: попытка открыть локальный preview в Chromium заблокирована ограничением среды (`ERR_BLOCKED_BY_ADMINISTRATOR`).
- Установка и отображение на физическом iPhone/Android.
- Успешная live-синхронизация расписания с `rasp.rea.ru` через внешний Gateway.

Тесты синхронизации и календарей проверяют локальную логику и обработку ошибок, но не доказывают текущую доступность официального портала.
