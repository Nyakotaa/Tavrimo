# QA Tavrimo 12.1.6 — несколько статических расписаний

## Проверенные группы

| Группа | Событий | Покрытие | Источник |
|---|---:|---|---|
| 15.14Д-ГГ04/266 | 46 | 09.11.2026–23.11.2026 | Встроенный снимок Vuzio, ранее проверен |
| 15.14Д-ММ05/26б | 48 | 16.11.2026–30.11.2026 | ICS из `Downloads(2).zip`, DTSTAMP 16.11.2026 13:21:20Z |

## Проверки новой группы MM05

- `X-WR-CALNAME` соответствует `Расписание 15.14Д-ММ05/26б`.
- Все 48 `VEVENT` распознаны текущим парсером.
- Не обнаружены `RRULE`, `RDATE`, `EXDATE`, `RECURRENCE-ID`, `DURATION`, отменённые события и неподдерживаемые часовые пояса.
- Диапазон событий: с 16 по 30 ноября 2026 года.
- Канонический код группы и латинская раскладка `15.14D-MM05/26b` сопоставляются с одной записью реестра.
- `loadStaticScheduleSnapshot` загружает запись из `manifest.json` и соответствующий ICS с revision-параметром.
- Основной `syncUniversitySchedule` применяет 48 событий в локальное расписание и выбирает режим `snapshot`.
- Предварительное кэширование нового ICS добавлено в Service Worker.
- В поле группы доступны подсказки только по двум зарегистрированным календарям.

## Регрессионный набор

Команда: `node tools/run_regression.mjs`

Результат: 16/16 тестов пройдены.

Проверки охватывают ручное планирование, расписание и задачи, парсер ICS, каталог статических снимков, импорт резервных копий, Sync Gateway, обработку HTTP 403, onboarding и согласованность версии релиза.

## Ограничения

- В поставке подтверждены только две группы, указанные выше.
- Все URL Vuzio, переданные отдельным сообщением, были одинаковыми; из повторяющейся ссылки нельзя получить расписания разных групп.
- Снимок MM05 статический, не подписан на обновления Vuzio и покрывает только 16–30 ноября 2026 года.
- Live-получение для остальных групп остаётся на прежнем Sync Gateway и требует отдельной проверки для каждого кода группы.
