# Как открыть Tavrimo 12.4.0 на телефоне

## Пока PR не слит

Версия 12.4.0 находится в отдельной ветке GitHub и в draft Pull Request. Публичная страница GitHub Pages ещё показывает текущую опубликованную версию; установленная PWA не обновится, пока пользователь не одобрит слияние и Pages не опубликует новую сборку.

Проверить изменения и CI можно в Pull Request:
https://github.com/Nyakotaa/Tavrimo/pull/3

## После одобрения и публикации

### iPhone

1. Открой публичную страницу Tavrimo в Safari.
2. Обнови страницу и проверь номер версии в «Ещё».
3. На экране «Сегодня» нажми «Импортировать .ics» и выбери файл в приложении «Файлы».
4. Перейди в «Неделя» и проверь события.
5. Для установки/обновления значка на экране «Домой» используй «Поделиться» → «На экран Домой».
6. После загрузки календаря открой приложение без интернета и проверь, что сохранённые события и задачи доступны.

### Android

1. Открой публичную страницу Tavrimo в Chrome.
2. Обнови страницу и проверь номер версии.
3. Нажми «Импортировать .ics» и выбери файл в системном файловом менеджере.
4. Проверь события на экранах «Сегодня» и «Неделя».
5. В меню Chrome выбери «Установить приложение» или «Добавить на главный экран».
6. Отключи интернет и проверь сохранённые события и задачи.

## Резервная копия

Перед обновлением желательно экспортировать JSON в «Ещё» → «Настройки» → «Экспортировать». При первом запуске 12.4.0 старые пары РЭУ автоматически переносятся в локальный календарь с сохранением ID и ссылок задач. Не очищай данные браузера до проверки миграции.


## Заставка запуска

После загрузки оболочки Tavrimo показывает логотип и анимированную полосу на короткое время, затем открывает экран «Сегодня». При повторных запусках уже установленной PWA Service Worker возвращает сохранённую оболочку из локального кэша. Первый запуск без кэша всё ещё зависит от времени ответа хостинга.
