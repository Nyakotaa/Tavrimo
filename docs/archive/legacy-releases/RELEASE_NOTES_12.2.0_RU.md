# Tavrimo 12.2.0 — Spotify-inspired Dark UI

## Что изменилось

- В существующий PWA перенесена тёмная тема по переданному `DESIGN.md`: фон `#121212`, поверхности `#181818` / `#1F1F1F`, карточки `#252525` / `#272727`.
- Функциональный акцент — зелёный `#1ED760`; семантические состояния используют красный `#F3727F`, оранжевый `#FFA42B` и информационный синий `#539DF5`.
- В верхней панели размещён оригинальный пиксельный логотип чашки Tavrimo и название, выровненные по центру.
- Кнопки и поиск получили pill-геометрию, карточки — компактные тёмные поверхности, элементы управления — более чёткую контрастность.
- На телефонах сохранена нижняя навигация; на широких экранах от 896 px используется боковая навигация.
- Убран переключатель светлой/системной темы: визуальная система теперь единая и тёмная. Старые значения темы в сохранённых данных не удаляются.

## Что намеренно не менялось

- Модель локальных данных `tavrimo-planner-v17` и schema version 17.
- Задачи, ручное планирование, проверки конфликтов, Focus, статистика, onboarding и импорт/экспорт JSON.
- Импорт ICS, два проверенных календарных снимка и существующая логика Sync Gateway.
- Личные данные продолжают храниться в браузере; они не отправляются на Sync Gateway.

## Ограничения

- Подтверждены только две встроенные группы из предыдущего релиза.
- Для остальных групп доступность live-синхронизации по-прежнему зависит от Sync Gateway и здесь заново не подтверждена.

## Проверка

- До редизайна: исходный регрессионный набор 12.1.6 — 16/16 тестов.
- После редизайна: обновлённый набор 12.2.0 — 16/16 тестов.
- `node --check` для клиентских JS-файлов — без ошибок.
- JSON-манифесты и release manifest — валидны.
- CSS parser — 0 ошибок.
- Физические устройства и live Sync Gateway в этой среде не проверялись.
