# Flowday 8.0.0 RC1 — чек-лист перед финальным релизом

## Планировщик
- [ ] Задача с дедлайном и временем помещается только до этого времени.
- [ ] Задача без времени дедлайна считается до конца дня.
- [ ] 15м/30м/1ч/2ч занимают соответствующий размер окна.
- [ ] Высокий/средний/низкий приоритет меняют порядок при сопоставимых дедлайнах.
- [ ] Ручной слот не конфликтует с другими задачами, обедом и рабочими часами.
- [ ] Изменение дедлайна/длительности/приоритета перепланирует авто-задачу.
- [ ] Изменение ручной задачи сохраняет ручной режим.
- [ ] Выполнение и возврат не сбрасывают режим без необходимости.

## Календарь
- [ ] Можно открыть любую дату.
- [ ] Можно перейти на предыдущую/следующую неделю.
- [ ] Процент занятости совпадает с фактически зарезервированным временем, включая буфер.

## Focus
- [ ] Таймер запускается и ставится на паузу.
- [ ] Выбор задачи блокируется во время активной сессии.
- [ ] Закрытие окна не сбрасывает активную сессию.
- [ ] После возврата из background время рассчитывается по timestamp.

## Данные
- [ ] Экспорт создаёт JSON.
- [ ] Импорт валидного JSON восстанавливает задачи.
- [ ] Импорт битого JSON не ломает приложение.
- [ ] Неполный слот не создаёт «осиротевшую» задачу.

## PWA
- [ ] Приложение открывается по HTTPS.
- [ ] Установка через Safari создаёт Web App.
- [ ] После первого открытия приложение работает без интернета.
- [ ] При выходе новой версии появляется кнопка «Обновить».
- [ ] Новая иконка появляется после удаления/повторного добавления Web App.
