# Переименование в Tavrimo

Начиная с версии 10.0.0 приложение называется **Tavrimo**. Пользовательские тексты, manifest, GitHub-описание, документация и резервные копии используют новое имя.

Старые ключи локального хранилища с именем прежнего приложения специально сохранены только для миграции данных. Они не являются частью пользовательского интерфейса.

Название выбрано как редкое вымышленное слово. Быстрая текущая проверка веба и каталогов приложений не показала очевидного совпадения с планировщиком под именем Tavrimo, однако это не является юридической гарантией отсутствия товарных знаков, компаний, доменов или других прав на название. Перед публичным коммерческим релизом стоит отдельно проверить товарные знаки и домены.
