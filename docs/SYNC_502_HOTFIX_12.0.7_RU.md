# Tavrimo 12.0.7 — REA Sync Hotfix

Исправлена причина 502 на этапе выбора группы и загрузки расписания.

## Что изменилось
- добавлен прямой переход `https://rasp.rea.ru/?q=<группа>`;
- добавлено несколько стратегий выбора результата из autocomplete/listbox;
- убрано автоматическое нажатие «Обновить» на портале РЭУ после выбора группы;
- если расписание видно на странице, оно сразу разбирается из DOM/текста и преобразуется в iCalendar;
- fallback не зависит от события скачивания `.ics`;
- обновлена диагностика логов (`REA_DIRECT_OK`, `REA_DIRECT_SELECT_OK`, `REA_RENDERED_PRIMARY`);
- сохранён ручной импорт `.ics` как резервный вариант.

## Источник данных
Официальный портал расписания РЭУ: https://rasp.rea.ru/
