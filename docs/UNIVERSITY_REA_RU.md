# Расписание РЭУ в Tavrimo

Источник: официальный портал расписания РЭУ — https://rasp.rea.ru/

## Подключение

1. Откройте `https://rasp.rea.ru/`.
2. Найдите свою группу по номеру.
3. Экспортируйте расписание в календарный файл `.ics`.
4. В Tavrimo откройте **Неделя → РЭУ → Подключить**.
5. Укажите номер группы.
6. Импортируйте `.ics`.

После импорта Tavrimo сохраняет события локально. Карточка занятия показывает время, тип, преподавателя и аудиторию, если они присутствуют в экспортированном календаре.

## Работа с задачами

В окне пары есть действие **«Поставить задачу к этой паре»**. Tavrimo создаёт обычную ручную задачу с дедлайном на начало пары и сохраняет ссылку на событие.

Связанную задачу можно позже открыть и отвязать от пары.

## Важное ограничение

Интеграция основана на официальном календарном экспорте, а не на внутреннем API РЭУ. Поэтому обновление расписания выполняется повторным экспортом и импортом `.ics`.

По данным самого портала, ранее загруженное расписание может устаревать; при отсутствии сети портал показывает только ранее загруженные данные. Поэтому Tavrimo сознательно маркирует импорт временем обновления и хранит именно последнюю загруженную копию.
