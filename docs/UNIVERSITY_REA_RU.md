# Расписание РЭУ в Tavrimo

Официальный портал расписания РЭУ: https://rasp.rea.ru/

По данным портала и актуальным страницам РЭУ, расписание можно искать по номеру группы, а портал также предоставляет экспорт расписания в календарь. РЭУ указывает, что расписание появляется на портале после утверждения и его следует проверять перед занятиями.

## Tavrimo 12

Главный экран приложения — учебное расписание. Пользователь указывает группу один раз. Sync Gateway получает официальный календарный экспорт от `rasp.rea.ru`, после чего PWA:

- сохраняет расписание локально;
- показывает пары по дням;
- отображает время, преподавателя, аудиторию и тип занятия, если они есть в источнике;
- блокирует время пары для ручных задач;
- позволяет создать задачу, привязанную к конкретной паре;
- сравнивает новые версии расписания и обновляет данные при изменениях.

## Почему нужен Gateway

GitHub Pages — статический хостинг. Он не запускает серверный браузер и не может надёжно пройти интерактивную процедуру поиска группы на внешнем сайте. Поэтому live-синхронизация вынесена в `sync-service`, а PWA остаётся лёгким и offline-first.

## Резервный импорт

Если портал временно недоступен для Gateway, в окне «Расписание РЭУ» остаётся ручной импорт `.ics`. Уже импортированное расписание продолжает работать офлайн.
