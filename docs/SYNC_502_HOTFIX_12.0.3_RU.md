# Tavrimo 12.0.3 — исправление 502 Sync Gateway

## Симптом

РЭУ успешно открывает расписание группы, но Tavrimo получает `502`: экспорт iCalendar не обнаруживается.

## Почему

В текущем интерфейсе rasp.rea.ru экспорт может генерироваться на клиенте через JavaScript/Blob и не обязан появляться как обычное HTTP-скачивание. Поэтому одного `page.waitForEvent('download')` недостаточно.

## Исправление

Gateway теперь пытается последовательно:

1. обычный Playwright download;
2. `text/calendar`/`.ics` ответы;
3. client-generated Blob/data URL;
4. ссылки и сетевые URL экспорта;
5. fallback-парсинг уже отрисованного расписания.

Последний вариант строит валидный iCalendar на стороне Tavrimo из реальных дат, времени и содержимого занятий, которые уже отображены официальным порталом.

## Проверка

После deploy открыть `/api/rea/health`, затем повторить загрузку группы. При ошибке 502 в логах теперь будет полный контекст.
