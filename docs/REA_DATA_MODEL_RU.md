# Данные расписания РЭУ

Каждое событие хранит:

- стабильный `id`;
- исходный `uid` из ICS, если он есть;
- дату и интервал времени;
- название и тип занятия;
- преподавателя;
- аудиторию;
- текстовое примечание.

Стабильный ID строится по содержимому события и UID, поэтому повторный импорт без изменения события не ломает привязку задач.

Задачи хранят `linkedUniversityEventId`. Если соответствующее событие больше не приходит в новом экспорте, связь автоматически удаляется, а сама задача остаётся.
