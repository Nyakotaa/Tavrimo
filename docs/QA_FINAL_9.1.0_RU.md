# Tavrimo 9.1.0 Final — QA / Regression

Дата прогона: 2026-09-27

## Область

Финальная версия работает в режиме **manual-only**: приложение никогда не выбирает время задачи само и не запускает автоматическое перестроение расписания. Пользователь либо указывает дату и время вручную, либо оставляет задачу без времени.

Проверены логика данных, ручное расписание, дедлайны, длительность, приоритет, резерв, конфликтные слоты, Focus, календарь, фильтры, настройки, импорт/экспорт, удаление и сброс данных.

## UI regression

Проверены вручную через автоматизированный мобильный сценарий:

- чистый запуск без демо-задач;
- отсутствие старых авто-функций и кнопок;
- выбор даты: открыть, предыдущий/следующий день, «Сегодня»;
- создание задачи с ручным слотом;
- отображение реальной занятости дня;
- открытие задачи через «Дальше»;
- запрет слота после дедлайна;
- запрет конфликтующего слота;
- запрет неполной даты/времени;
- сохранение задачи без времени без автоматического назначения;
- изменение длительности и пересчёт загрузки;
- выполнение/возврат с сохранением ручного слота;
- снятие времени;
- календарь: предыдущая/следующая неделя и «Сегодня»;
- фильтры задач;
- Focus: старт / пауза / сброс;
- Статистика / Состояние плана / Настройки;
- экспорт резервной копии;
- удаление задачи;
- импорт JSON с дублирующимися ID;
- полный сброс данных.

## Проверка manual-only политики

В runtime/UI отсутствуют:

- `planBtn`;
- `manualScheduleToggle`;
- `moveTaskBtn`;
- `replanFromSheet`;
- `planningSheetBackdrop`;
- `autoPlanAll`;
- `scheduleSingleTask`.

В пользовательском интерфейсе нет предложения автоматически подобрать или перестроить время.

## Ограничение среды

Полноценная проверка установки, обновления Service Worker, offline launch, background Focus и фактической иконки на **физическом iPhone** в этой среде невозможна. Код, PWA-метаданные, cache version и мобильные UI-сценарии проверены автоматически; финальная физическая проверка на iPhone остаётся ручным шагом перед публикацией в GitHub Pages.

## Итог

**GO для финальной публикации** при условии одного физического smoke-теста на iPhone после загрузки на HTTPS:

1. открыть Tavrimo в Safari;
2. добавить на экран «Домой»;
3. проверить новую иконку;
4. обновить до `9.1.0 Final` поверх старой версии;
5. отключить интернет и открыть приложение;
6. создать задачу без времени и проверить, что Tavrimo не назначает слот сам;
7. назначить слот вручную и проверить загрузку дня;
8. запустить Focus и свернуть приложение.
