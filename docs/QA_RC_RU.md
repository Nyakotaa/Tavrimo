# QA — Tavrimo 8.0.0 RC1

## Автоматические проверки
- `node --check app.js`
- `node --check sw.js`
- `node tools/test_scheduler.mjs`
- проверка уникальности HTML id;
- проверка ссылок на локальные ресурсы;
- проверка PWA manifest;
- проверка набора иконок.

## Регрессионные сценарии
- Пустой первый запуск.
- Создание автоматической задачи.
- Жёсткий дедлайн с точным временем.
- Длительности 15м / 1ч / 2ч и их влияние на размер слота.
- Разные приоритеты и порядок автопланирования.
- Ручной слот внутри рабочего времени.
- Ошибка ручного слота при конфликте.
- Ошибка ручного слота при пересечении с обедом.
- Выполнение ручной задачи и возврат в работу.
- Глобальное перепланирование после выбора будущей даты.
- Перенос после изменения дедлайна/длительности.
- Focus: запуск, пауза, закрытие окна, повторное открытие.
- Статистика выбранной недели.
- Импорт некорректной резервной копии.
- Навигация по неделям.
- Светлая/тёмная/системная тема.

## Результат RC1
Автоматические scheduler/UI сценарии, доступные в рабочей среде, пройдены без JavaScript ошибок. Реальный физический iPhone в этой среде недоступен, поэтому финальный device-check должен быть сделан перед production-релизом.
