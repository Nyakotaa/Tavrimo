# Как открыть Tavrimo 12.4.0 на телефоне

Обновление размещается в ветке `update-12.4.0-clean-interface`. Основной сайт `main` не меняется до отдельного решения о слиянии.

## Проверка на iPhone

1. Открой в Safari адрес страницы предпросмотра ветки, когда она будет опубликована через отдельное окружение Pages/PR preview.
2. Проверь экраны «Сегодня», «Неделя», «Задачи», «Ещё» и «Профиль».
3. Нажми «Импортировать .ics» и выбери календарный файл в приложении «Файлы».
4. В меню Safari нажми «Поделиться» → «На экран Домой», чтобы добавить PWA, если она ещё не установлена.
5. После первого запуска с интернетом открой приложение ещё раз без сети и проверь сохранённые задачи и события.

## Проверка на Android

1. Открой адрес предпросмотра в Chrome.
2. Импортируй `.ics` через кнопку на экране «Сегодня».
3. Открой меню Chrome → «Установить приложение» или «Добавить на главный экран».
4. Отключи интернет и проверь, что ранее импортированные события и задачи остаются доступны.

## Перенос данных

Перед обновлением желательно экспортировать JSON-копию в «Ещё» → «Настройки» → «Экспортировать». При первом открытии 12.4.0 старые данные автоматически нормализуются и мигрируют локально. Не очищай данные браузера до проверки миграции.

Важно: страница GitHub Pages основного сайта не обновится до слияния ветки и публикации релиза. Ветка обновления сама по себе не меняет установленную PWA.
